# 학습관 변화와 영향 학생 — 구현 계획

사용자가 승인한 범위: 개인 상담 학생을 기본 선으로 띄우는 시안 폐기. 학습관 지표를 우선하고, 지표 hover/click에서 기여 학생·제외 효과·개인 상세로 이어진다. 로컬 DB에 대/중/소 3지점, 총100명(60/30/10), 최근7일과 그 이전28일을 저장한다. 운영 분포 재현/상담 효과 검증을 주장하지 않는다.

- [x] 기존 JSON을 유지하는 로컬 DB 예시 어댑터와 격리된 demo 테이블/seed를 구현한다. 기존13명 회귀 fixture·상담 DB를 보존한다.
- [x] 개인의 같은요일 이전28일 기준과 최근7일의 비교를 계산하는 순수 모델을 구현하고 수치 검증한다.
- [x] 학습관 카드4종(학습 시간 변화, 입실 지연, 결석, 계획 미제출)과 날짜7개, 지표별 hover/click 세부를 구현한다.
- [x] 기여 학생은 전체 변화에서 차지하는 부호 있는 양으로 정렬한다. 학생 단위 제외/복원은 관측집단·비교기준 양쪽에 동일하게 적용하고, 전체값과 적용값을 함께 표시한다.
- [x] 입실 시각 자체를 백분율로 나누지 않는다. 개인 같은요일 기준 대비 분 차이와, 기존 설정 지연 기준을 넘긴 관측의 비율(분모 명시)을 제시한다. 표본 없는 값은 0으로 채우지 않는다.
- [x] 학생 상세 이동, 제외 리셋/지점변경, 동일 기간/분모/누락, 60명 지점과10명 지점·2테마/좁은 폭을 실제 브라우저에서 검증하고 독립 리뷰한다.

파일 분리: DB 작업은 `common/integration/learnershigh/demo` 및 `scripts/demo`와 전용 profile; 집계는 `model/branchOverview.ts`; UI는 `weekly/BranchOverviewDashboard.tsx`와 전용CSS. `CareBranchMetrics`의 최종5 진입만 새 UI로 교체한다. API/DB 운영계약 변경 없음. 로컬 전용 source 테이블은 운영 Flyway에 추가하지 않는다.
