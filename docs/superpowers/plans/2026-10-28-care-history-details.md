# 관리 이력 학생별 조회와 원문 펼치기

사용자 요청: 관리 이력에서 당시 작성한 내용과 학생별 기록을 확인한다. 기존 API의 content는 원문이며 추가 필드/DB/Endpoint는 필요 없다. 승인된 진행 범위 안에서 구현한다.

설계: 기존 날짜/학생/내용 목록을 보존한다. 상단 학생 선택(전체 명부, 기록 없는 학생 포함), 이름 검색, 전체 복원을 추가한다. 학생 이름은 해당 학생의 이력 필터로 작동하며 다른 탭으로 이동하지 않는다. 각 행의 내용 버튼으로 행 바로 아래에 기록 원문을 펼친다. 원문 줄바꿈/긴 내용은 보존한다. 별도 학생 지표 확인은 상세 안의 명시적 동작으로만 제공한다. 없는 작성자·과거 지표는 추정하지 않는다.

대안 검토: 별도 페이지는 현재 위치를 잃고, 팝업은 이력 연속 비교에 불리하다. 행 내 펼침을 사용한다. 전체 상담 건의 원문을 초기 화면에 노출하는 것은 가독성을 낮추므로 목록은 한 줄 요약, 원문은 펼침으로 구분한다. 요약은 표시만 줄이고 저장 내용은 변경하지 않는다.

- [x] API 재사용: loadCareHistoryPage가 전체 명부+이력 한 번 조회. 기존 loadCareHistory 반환형 유지.
- [x] 회귀 테스트: 학생 필터/기록 없음/전체 복원, 긴 원문과 줄바꿈, 같은 행 펼침·접기·다른 탭 이동 없음, 소스 실패 복구.
- [x] AllHistory와 전용 CSS: 학생 선택과 행 내 원문/상담 방식/기록일 표시. 현재 학생 상세 이동은 명시적 버튼으로 유지.
- [x] 타입·린트·모델·Playwright 1600/850/390 및 light/dark, 직접 브라우저 확인.

기존 학습관 지표 게이트 및 BE 개인 기준 비교 불일치 작업은 병행 중이며, 이 기능으로 전체 검수를 통과했다고 표시하지 않는다.
