# 학생 케어 5·6·7

사용자 피드백: 전체 학생 표를 기본으로, 기호 해독 줄이기, 세부 수치는 hover/focus로 즉시, 최근7일 전체 기록 비교, 큰 데이터 편차, 짧은 범례. 1~4는 비교용으로 유지한다.

- 5: 주간 명부. 학생별 행×7일 칸에 학습 시간과 첫 입실 시각을 배치한다. 입실/계획은 따로 집계 열을 두고, 날짜 칸은 미입실·미제출 같은 예외만 강조한다. 작은 막대는 학습량에만 사용한다.
- 6: 지표별 비교표. 전원 행에 주간 학습량, 일별 계획·실제, 입실 시각의 분포, 제출 상태를 나란히 놓는다. 열별 동일 축을 사용하고 hover로 정확값을 읽는다. 학생행 선택 시 바로 아래7일 전체 비교표를 펼친다.
- 7: 날짜 중심 기록장. 각 학생에 입실/학습/계획 제출3행과 날짜7열을 보여준다. 미제출 여부는 얇은 색표식+텍스트, 시간은실제수치, 계획/실제는한셀 비교로 표시한다. 추가 상세 클릭 없이 기록이 기본 노출된다.

세 시안은 같은 편차 큰 예시자료를 쓴다. 10분~11시간40분, 오전/야간 입실,0·미기록·휴무·삭제된 휴무 가정, 계획 초과/미달을 포함한다. 원본1 및2~4 예시자료는 바꾸지 않는다.

범례는 ‘최근7일’/‘이전28일’, 동일요일 비교는 ‘요일 평균’. 기간/대상/분모는 화면상단과 펼침설명에1회 적는다. 실제 평균주체/기간은hover에서도 확인할 수 있다.
