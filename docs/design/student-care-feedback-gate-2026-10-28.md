# 학생 케어 화면 — 대화 전체 피드백 게이트

근거: 이 대화의 사용자 메시지와 첨부 화면 전체. 구현 보고, 테스트 통과, 이전 에이전트의 의견을 사용자 승인으로 취급하지 않는다. 최신 지시가 과거 제안을 대체하며, 아래 항목은 모두 결과물 제출 전 개별 확인한다. 이 문서는 발표자료나 일반 코드 품질 체크리스트가 아니다.

## 판정 규칙

- 각 항목은 실제 코드·API·화면·실측 중 적합한 근거로 확인한다. “구현했음”은 검증 근거가 아니다.
- 미확인, 부분 충족, 오독 가능성, 가림·겹침, 데이터 은폐가 하나라도 남으면 전체 통과 금지. 수정 후 해당 항목과 영향받은 검사를 다시 수행한다.
- 재검수 표기는 `PASS: 근거`, `FAIL: 현상/재작업`, `미확인: 필요한 확인` 중 하나로 기록한다. 체크박스는 근거를 확인한 뒤에만 체크한다.
- 과거 검증 결과를 변경된 화면의 근거로 재사용하지 않는다. 테스트 통과와 가독성 검토는 각각 필요하다.
- 검수 후 새 사용자 피드백이 오면 관련 항목의 통과를 취소하고 갱신한다.

## 1. 범위와 원본 보존

- [x] G01 원본 케어1의 기존 구성·동작을 임의로 재설계하지 않았다. 최종안은 기존 기능을 개선하며 새 시스템으로 대체하지 않는다.
- [x] G02 현재 메뉴는 원본1, 재번호된2·3, 최종5다. 기각된 시안·버튼 스왑을 다시 끼워 넣지 않았다.
- [x] G03 학생별은 전체 학생의 간략 목록 → 학생 선택 → 상세다. 특이사항 학생만 명부에 남기거나 전체 명부에 상세 그래프를 반복하지 않는다.
- [x] G04 특이사항 학생은 목록 위쪽에 배치하고 테두리·짧은 상태로 구별한다. 정상 학생도 검색·지점 변경 후 누락되지 않는다.
- [x] G05 학생 케어 영역에 한정된 수정이다. 존재하지 않는 승인 휴무, 외부 알림, 불이익 판정 기능을 만들지 않는다.

## 2. 학습관별 핵심 목적 — 반드시 그래프 자체로 확인

- [x] G06 학습관별은 개인 상세 화면의 복제품이 아니다. 전체 규모와 전반적인 상태를 먼저 이해할 수 있다.
- [x] G07 총100명을 60·30·10명으로 나눈3지점 구성을 유지한다. 9명 등의 변화 학생 수를 전체 인원처럼 읽게 만들지 않는다. 지점 이름에는 임의의 대형·중형·소형 꼬리표를 붙이지 않는다.
- [x] G08 선택된 특정 학생만 그래프에 반영하는 것이 아니라 전체 학생이 분포에 반영된다. 누가 포함·제외됐는지와 관측 인원을 확인할 수 있다.
- [x] G09 평균에 묻힌 여러 학생의 큰 감소·반복 결석·입실 지연을 동시에 식별할 수 있다. 그래프는 평균뿐이고 문제 학생을 찾으려면 다른 곳을 뒤져야 하는 구조는 실패다.
- [x] G10 평균과 학생 분포 범위를 함께 보여주고, 범위에서 크게 벗어난 학생은 그래프에서 구분된다. 평균 띠·개별 점·선의 정체가 범례와 정확값에서 명확하다.
- [x] G11 3시간형·종일형, 오전형·저녁형의 정상 개인 차이를 문제로 표시하지 않는다. 개인의 평소 패턴 대비 변화와 집단 분포를 함께 고려한다.
- [x] G12 학습 시간을 많이 한 것 자체를 상담 문제/부정적인 이상값으로 표시하지 않는다. 통계적 분포 밖 값과 상담 판단은 동일하다고 주장하지 않는다.
- [x] G13 학습관 총 학습량을 주요 성과 지표로 사용하지 않는다. 평균 학습 시간과 개인 비교 기능을 보존한다.
- [x] G14 입실 시각의 절대 평균이나 상쇄된 +3.3분만으로 학습관 상태를 대표하지 않는다. 지연의 분포·반복과 영향을 주는 학생이 드러난다. 시각 자체를 %로 나누지 않는다.
- [x] G15 사용자가 불필요하다고 지적한 ‘60분 이상 늦은 입실’ 별도 요약을 제거한다. 운영 기준은 설정에 두며 그래프 주변에 기준 설명을 반복하지 않는다.
- [x] G16 학생을 여러 명 선택해 비교하고 구별 가능한 색을 쓴다. 선택한 학생 이름과 실제 선·정확값이 일치한다. 선택이 숨겨져 해제할 수 없거나 과다 선택으로 난잡해지지 않는다.
- [x] G17 학생 제외·복원은 전체 분포와 평균에 일관되게 반영된다. 최근 값과 비교 기준 모두 동일한 학생을 제외하며 API 원본·상담 상태를 수정하지 않는다.

## 3. 데이터 의미와 지표별 표현

- [x] G18 표시 기간은 최근7달력일, 기준은 그7일을 제외한 이전28일이다. 서로 겹치지 않으며 비교 대상에 이번 주가 섞이지 않는다.
- [x] G19 날짜7개와 요일을 모두 읽을 수 있다. 시간축 눈금은 줄일 수 있지만 날짜는 생략하지 않는다. 결석·미제출이 언제인지 알 수 있다.
- [x] G20 출결·제출 여부는 날짜별 상태로 표현한다. 0/1·1회에 긴 수량 막대, 흩어진 날짜 버튼 나열로 대체하지 않는다.
- [x] G21 학습 시간·입실 시각·비율·범주형 상태에 각각 적합한 표현을 사용한다. 공통 막대그래프로 자가복제하거나 텍스트만 채운 화면을 만들지 않는다.
- [x] G22 실제0, 결석, 일정 없음, 미확인을 구별한다. 원본이 없는 날을 결석/미제출/정상/0으로 꾸미지 않는다. 일정이 확인되지 않았으면 결석 확정하지 않는다.
- [x] G23 계획은 원본 코드의 의미·단위를 확인한다. 시간과 과목 비율을 편의대로 바꾸지 않는다. ‘계획 대비 진행률’이100%를 넘는 뜻을 정확히 유지한다.
- [x] G24 과목 비중10% 대90%, 큰 계획·실행 차이가 같은 축에서 명확하다. 축이 잘리거나 유사한 예시만 넣어 차이를 숨기지 않는다.
- [x] G25 하루 과다 학습이 다른 날의 반복 감소를 상쇄해 문제 학생이 사라지지 않는다. 반복 일수와 실제 날짜를 검증한다.
- [x] G26 지점별 설정과 초기값이 자습 학습관 맥락에 맞는지 구분한다. 검증되지 않은 기준을 업계 표준/최적값으로 주장하지 않는다.

## 4. 상호작용 — 클릭한 컴포넌트 안에서 종료

- [x] G27 지표·날짜 클릭은 해당 카드 안에서 펼쳐진다. 맨 아래 공통 상세로 자동 이동하지 않는다. 클릭 전후 스크롤 위치를 측정한다.
- [x] G28 학생·문제 점 선택도 같은 컴포넌트에서 세부 기록을 확인하고 접는다. 화살표 바로가기/페이지 이동에 의존하지 않는다.
- [x] G29 결석 날짜 클릭 시 해당 결석 카드 안에 그날 결석한 학생이 펼쳐진다. 사용자가 괜찮다고 한 결석 표현을 불필요하게 재설계하지 않는다.
- [x] G30 hover와 키보드 focus에서 학생 이름·날짜·정확한 시각/시간·평소 값·차이를 확인한다. 그래프 아래 멀리 떨어진 내용이 바뀌어 시선을 왕복하지 않는다.
- [x] G31 불투명 세로 박스·정체불명 네모·스크롤 툴팁·날짜 가림이 없다. 가장자리와 최대 다중 선택에서도 툴팁을 실측한다.
- [x] G32 상세 기록을 여러 번 ‘다음’으로 넘겨야 최근7일을 비교하는 구조가 아니다. 불필요한 접기·중복 설명을 제거한다.
- [x] G33 상담 입력은 상시 확인 가능하고 과거 관리 이력만 필요한 경우 접는다. 상담·다음 확인·저장 기능이 보존된다.

- [x] G35 도래·판단 필요·지표 추세·비등원·입실 기록 없음 남발·확인 필요/재확인 중복 등 지적받은 용어를 전체 변경 범위에서 재검토한다. 기존에 확인된 출결은 입실/결석으로 쓴다.
- [x] G36 주요 변화값을 흐린 회색 작은 글자로 숨기지 않는다. 이름·날짜·수치·상태의 위계가 있고 장황한 텍스트가 그래프를 대체하지 않는다.
- [x] G37 밝은/어두운 테마에서 실제 화면을 확인한다. 흰 배경 혼입, 낮은 대비, 글자·버튼 잘림이 없다.
- [x] G38 1600/850/390px에서 날짜·텍스트 겹침·문서 가로 넘침·클릭 영역을 측정한다. 스크롤 금지는 절대 규칙이 아니지만 글씨를 작게 압축해 맞추지 않는다.

## 6. 데이터·API·검수 근거

- [x] G39 DB에100명의35일 기록이 존재하고3지점 인원이 맞는다. 명부·metrics·학생 detail이 동일 원본을 쓴다. 데이터 부족을 편의적인 FE fallback으로 감추지 않는다.
- [x] G40 정상 단시간/장시간/요일 차이, 일시·지속 감소/지연, 회복, 결석, 미제출, 극단 비율, 초과 진행, 누락 케이스를 확인한다. 하루 안에 불가능한 시간 예시는 없다.
- [x] G41 오류·로딩·빈 상태를 구별한다. 원본 변경 후 오래된 지점 목록의 오류를 복구하고,503 등을 예시 데이터로 치환하지 않는다.
- [x] G42 관련 타입·린트·빌드·모델·상호작용 검사를 실행했다. API 평균/분포와 화면 값을 독립적으로 대조했다. API/DB 변경 여부와 실제 운영 연동 한계를 숨기지 않는다.
- [x] G43 실제 오른쪽 브라우저에서 직접 조작했다. 캡처와 Playwright 실측 결과가 최종 코드·DB를 대상으로 한다.
- [x] G44 맥락 없는 에이전트에게 실제 화면을 읽게 했다. 리뷰가 실행되지 않았거나 실패했다면 통과로 적지 않는다.
- [x] G45 이 체크리스트 전체를 기준으로 독립 적대적 리뷰를 했다. 항목별 의심과 반례를 먼저 찾고, 지적 사항을 수정한 후 재검수했다.
- [x] G46 현재 디자인·인수인계 문서의 기각된 표현/검증 주장을 정리했다. 발표자료 수정은 별도 작업이며 이 UI 게이트에 섞지 않는다.

## 7. 케이스 적합성 — 학생 간 차이는 그 자체로 문제가 아니다

- [x] G47 총100명의 서로 다른 생활·학습 패턴을 전제로 표시법을 골랐다. 차트를 먼저 정하고 맞는 데이터만 골라 넣지 않는다. 60/30/10명 각 지점의 전체 관측이 분석 대상이며, 전체100명과 지점 인원을 혼동하지 않는다.
- [x] G48 **정상 차이 반례:** 평소 오전10시 입실/오후7시 입실, 평소3시간 학습/종일 학습, 평일 짧음/주말 장시간인 학생을 각각 넣어 확인했다. 단순히 집단 평균에서 멀다는 이유로 문제 학생에 포함되면 실패다.
- [x] G49 **개인 변화 반례:** 평소 대비 반복 지연·학습 감소가 있지만 절대값은 집단 평균 부근인 학생도 식별된다. 예: 평소10시간→6시간인 학생의 감소를 평소3시간형 학생과의 절대량 비교로 가리지 않는다. 평소19시→20시인 학생은 평소20시를 유지하는 학생과 구별된다.
- [x] G50 **지표별 비교 단위:** 입실은 개인 평소 대비 분 차이, 학습량은 개인 평소 대비 변화와 실제 학습 시간을 구분한다. 원시 시각·총량·변화율·중간 분포의 단위와 의미를 뒤섞지 않는다. 분포 밖에 있다는 사실만으로 정상/상담 필요를 확정하지 않는다.
- [x] G51 **가려짐 반례:** 정상 학생이 대부분인 경우, 여러 문제 학생이 동시에 있는 경우, 집단 전체가 변한 경우, 하루의 극단값이 반복 문제를 상쇄하는 경우를 각각 검증했다. 평균이나 분포 띠 하나만 보고 이상이 없다고 결론 내리지 않는다.
- [x] G52 **사례 선행 검토:** 위 케이스와 판별 과제를 먼저 정의한 뒤, 다중 시계열·개인 기준 편차·집단 분포·선택/상세 상호작용에 대한 선행 사례를 읽고 비교했다. 출처별 실제 적용점·부적합한 점을 기록한다. 구현 후 비슷한 차트 링크를 붙이는 것은 통과 근거가 아니다.

G47–G53은 화면·모델·독립 리뷰를 모두 대조해야 통과한다. 현재 모두 미확인이다. 표본 케이스를 만족하는 표시법을 아직 확정·승인했다고 기록하지 않는다.

### 지표별 조사 근거와 추가 반례

[지표의 성질·선행 사례·적용 여부 분석](student-care-metric-research-2026-10-28.md)에6개 지표와 표시법별 적용/보류 이유를 정리했다. [가상 반례13개](student-care-metric-cases-2026-10-28.json)는 Node22 스크립트의 산술 assert로 확인했다. 실제DB 관측이나 UI 검증 결과는 아니다.

G50–G53 검수 시 다음 반례도 반드시 포함한다.

- 중간50% 범위를 정상 허용 범위로 오인하지 않는가. 범위 밖50% 전부를 문제로 표시하지 않는가.
- 집단 전원이 함께 변해 IQR 밖 학생이0명이어도 변화가 드러나는가.
- 개인별 변화율과 실제 감소 분을 함께 확인해 작은 분모의 과장을 피하는가.
- 개인 평균을 보정한 뒤에도 남는 개인별 변동 폭의 차이를 고려하는가. 같은요일4개 표본으로 정밀한 개인 정상 범위를 보장한다고 주장하지 않는가.
- 결석으로 줄어든 예정일 평균과 입실일 학습량 감소를 구분하는가.
- 개인 진행률의 평균과 실제합÷계획합의 서로 다른 분모를 혼용하지 않는가.
- 과목 비중 하락만으로 해당 과목 시간 감소를 단정하지 않는가.
- 같은 값의 여러 학생이 겹쳐도 모두 식별·선택 가능한가.
- FE 같은요일 비교와 BE 기간 전체 비교, 미제출의 일정 제외, 과목 계획/실제의 표본 차이를 숨기지 않는가.

조사 문서 작성은 G52의 근거 추가이며 UI 게이트 통과를 뜻하지 않는다. G06–G17/G27–G31/G43–G45/G47–G53은 최신 화면으로 재검증해야 한다.
