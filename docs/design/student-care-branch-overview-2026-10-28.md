# 학습관 전체 변화와 영향 학생 — 2026-10-28

## 이번 피드백의 우선순위

사용자는 학습관 탭에서 한 상담 학생 선이나 상담 목록을 먼저 제시하는 것을 기각했다. 학습관 전반의 변화, 개인 패턴을 고려한 입실 변화, 영향이 큰 학생, 학생 제외 전후 비교가 우선이다. 최종5의 학습관 진입을 `BranchOverviewDashboard`로 교체했고 이전 큐/자동 개인선은 더 이상 렌더링하지 않는다. 학생별 목록→개인 상세, 원본1 및 비교2/3은 유지한다.

## 지표의 의미

- 학습 시간: 최근7일 각 날짜의 실제 분과 해당 학생의 이전28일 같은요일 평균을 짝지어 합산한다. 양쪽이 있는 관측만 비교한다. 전체 변화%의 학생별 기여%p 합은 전체 변화%와 같다. 실제0은 포함하고 결측은 양쪽 비교에서 제외한다.
- 입실 시각: 실제 시각−개인의 이전 같은요일 평균 시각을 관측별로 구하고 평균한다. 오전형/저녁형의 시각 자체를 비교하거나 시각을 %로 나누지 않는다. %는 설정된 지연 분(현재60분) 이상인 관측/비교가능 입실 관측이다. 학생별 전체 평균 기여는 학생 편차 합/전체 비교관측 수로 계산한다.
- 결석: 예정=true이고 출결이 확인된 관측의 결석 건수다. 일정 미확인·원본 누락을 결석으로 바꾸지 않는다. 과거 결석 일별 응답이 없으므로 과거 결석률을 만들지 않는다.
- 계획 제출률: 기록이 확인된 제출/미제출 중 제출 비율이다. 명시적으로 예정이 없거나 제외된 날은 분석에 포함하지 않는다. 일정 미확인이어도 제출 상태 자체가 확인되면 포함한다. UI는 ‘기록 확인일 기준·등원 제외일 미포함’으로 범위를 밝힌다. 과거 제출률은 응답에서 계산할 근거가 없어 새로 추정하지 않는다.
- 제외/복원: source/상담 상태를 변경하지 않는 화면 내 분석이다. 최근 관측과 개인 비교기준에서 같은 학생을 모두 빼고 분모도 다시 계산한다. 전체값→적용값, 포함/전체 인원, 제외 이름과 복원을 표시한다. 지점 변경 시 초기화한다.

## 표현과 상호작용

4개 카드가 먼저 보인다. 학습 시간은 날짜별 실제/기준 합계 쌍 막대, 입실 변화는 0기준 양방향 막대, 결석은 7개 날짜별 건수 셀, 제출률은 날짜별 비율 선이다. 날짜/요일7개를 유지한다. hover·focus에서 날짜·정확값·분모와 기여가 큰 학생을 읽고, 날짜/카드 제목 클릭 시 하단 인라인 학생별 영향 표를 연다. 표는 이름 클릭→개인 상세, 제외/복원, 검색/8명 단위 페이지 이동을 제공한다. 학생 간 기여는 부호 수치와 0중심 막대로 표시한다. 긴 텍스트 상담 명단은 초기 화면에 넣지 않는다. 모바일에는 카드가 한 열로 이어지며, 상세 표만 가로 스크롤 가능하다.

[ONS 시각화 원칙](https://service-manual.ons.gov.uk/data-visualisation/guidance/principles)의 중요한 비교를 먼저 정하는 원칙과 [Datawrapper의 기여도 표현 설명](https://www.datawrapper.de/academy/how-to-create-a-waterfall-chart)을 검토했다. 기여도를 누적된 학생 서열이나 문제 등급으로 해석하지 않도록 signed 영향값을 사용한다. 이 화면이 판별 정확도/업무시간을 개선했다는 실사용 효과는 미측정이다.
