# 학생 케어 화면 용어 정리 · 2026-10-24

## 범위
이번에 수정한 학생 케어 2~4의 제목, 학생 상태, 비교 차트, 일별 상세, 관리 기준 설정, 상담 입력, 확인 일정, 관리 이력, 오류 메시지, 툴팁과 접근성 이름을 검토한다. 보존용 student-care-v1 소스는 수정하지 않는다. 계산, 분류 조건, API 필드/Enum은 바꾸지 않는다.

## 확인한 실제 용례
- [러너스하이 서비스 안내](https://learnershigh.kr/service.php): 학습 현황, 학습 시간, 달성률, 과목별 학습 비율, 입실·퇴실.
- [클래스팅 업데이트](https://blog.classting.com/product-update-2402/): 학습 현황, 학습 리포트, 지도 필요 인원. 이 기능은 상담 필요 여부를 확정하지 않으므로 ‘지도 필요’를 그대로 적용하지 않는다.
- [클래스팅 교사 가이드](https://media.classting.com/files/classroom/20AdKu7l5ZazWKX6TWMQahrbwdA/2ftrfm3ExKLch7iI3NxFtYdWDdb.pdf): 학습 현황, 학습 관리 용례.
- [토스 공식 라이팅 원칙](https://toss.tech/article/8-writing-principles-of-toss): 사용자가 이해하는 말, 예측 가능한 버튼, 중복 설명 제거, 정확한 사실 전달을 적용한다.

‘확인 필요’ 같은 개별 관리 상태까지 단일한 교육업계 표준으로 정해져 있지는 않다. 서비스 공통 용어는 위 용례를 따르고, 이 제품 고유의 상태는 실제 조건과 필요한 행동을 직접 표시한다.

## 적용한 용어
- 지표 추세 → 학습 현황
- 지표 비교 → 학생별 비교; 비교할 지표 → 비교 항목
- 공부 시간 → 학습 시간
- 출결(일수 비교) → 입실 일수: 등록 일정이 없는 상태에서 결석으로 단정하지 않는다.
- 계획 대비 달성 → 계획 달성률
- 과목 계획/과목 비중 → 과목별 학습 비율
- 계획 제출(비율 비교) → 계획 제출률. 날짜별 기록은 제출/미제출을 유지한다.
- 판단 필요 → 확인 필요
- 점검일 도래 → 확인일 지남 / 오늘 확인: 기준일보다 지난 날짜와 같은 날짜를 구분한다.
- 다음 점검일 → 다음 확인일
- 판단 보류 → 학습 기록 부족
- 특이사항 기준/판단 기준 설정 → 관리 기준 설정
- 비교 기록 부족 → 비교할 데이터 없음
- 그대로/좋아짐/나빠짐 → 변화 없음/개선/악화
- 전체 이력 → 관리 이력
- 상담 방식·내용·결과의 축약 레이블 → 상담 방법·상담 내용·상담 결과
- 계획 미달성 → 계획 달성률 낮음; 과목 계획 미달성 → 학습 비율 차이
- FE 구현 설명 → 예시 데이터 안내
- 확인일 선택 ‘선택 없음’ → ‘4주 후’: 기존에도 28일을 저장하던 선택지이므로 날짜는 바꾸지 않고 표시를 바로잡는다.

## 유지한 용어
입실/미입실, 제출/미제출, 기록 없음, 제외, 관리 중/관리 종료, 상담 기록, 학습관은 기능과 운영 맥락을 직접 나타내므로 유지한다. 예시 데이터라는 표시와 새로고침 시 초기화 안내도 유지한다.

## 검증 기준
학생별 상태, 기한 전/당일/지난 일정, 설정, 상담 입력, 일별 상세, 학습관 비교에서 이전 표현이 사용자 문구와 접근성 이름에 남지 않아야 한다. 숫자·분류 조건은 기존 데이터 테스트로 확인한다. 원본 22개 소스 파일의 Git 해시를 비교한다.
