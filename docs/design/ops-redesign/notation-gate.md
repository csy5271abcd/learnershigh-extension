# 학생 케어 표시법 검토표와 패턴 대장

작성 2026-11-08. 표시법 후보는 이 문서의 검토표를 모두 통과해야 보고서에 올린다. 패턴 대장에 있는 패턴은 다시 쓰지 않는다. 새 후보를 만들면 대장에 올린다.

## 1. 검토표

후보마다 실제 화면 캡처(학생 4명: 권유진·장수빈·권하린·강도현, 1600·1280, 다크·라이트)를 보고 판정한다. 하나라도 아니면 고치거나 다시 만든다.

| 번호 | 질문 | 근거 |
|---|---|---|
| Q1 | 그림만 보고 지표의 양과 단위를 읽을 수 있는가(공부 시간은 몇 시간, 입실은 몇 시, 계획은 계획보다 많은지 적은지, 사진은 몇 번·몇 분) | 2026-11-08 지적 "시간이라는 지표가 사라졌다", F08 |
| Q2 | 1차원 표기가 아닌가. 값 하나를 점·막대 하나로 옮기는 데서 끝나지 않고, 그 값이 이 학생에게 평소인지(학생 과거·같은 요일), 학습관 안에서 어디인지, 왜 달라졌는지(다른 지표) 중 하나 이상을 함께 보이는가 | 2026-11-07·11-08 지적 "1차원적", F13 |
| Q3 | 칸(상자) 안에 글자·%·±가 없는가. 값을 글자로 늘어놓지 않는가. 정확한 값은 마우스·초점에서만 보이는가 | 2026-11-08 "박스 만들고 글자 넣고 % + - 절대 금지", F15 |
| Q4 | 범례나 해독 문구 없이 읽히는가. 색은 기준을 넘었는지 하나만 뜻하고, 모양 약속(○●□)이 없는가 | F17, plan-z 1장 |
| Q5 | 날짜 7개와 요일이 모두 보이는가. 미기록과 0, 결석과 예정 없음이 구분되는가. 시간 길이와 시각이 같은 모양으로 오해되지 않는가 | F08, F11, F12 |
| Q6 | 극단값(하루 12시간과 2시간, 2시간 늦음, 100% 넘는 달성)과 150명에서도 그림이 무너지지 않는가 | F13, F14, F16 |
| Q7 | 5주(35일)로 넓혀도 읽히는가. 아니면 넓히지 않는 이유가 그림 자체에 있는가 | 2026-11-08 "5주도 보여줄 방법" |
| Q8 | 경계가 분명한가(칸·줄·영역이 어디서 끝나는지, 정렬, 다른 지표와 붙어 보이지 않음) | 2026-11-08 "경계의 모호함" |
| Q9 | AI 냄새가 없는가(의미 없는 둥근 칩, 연한 배경 남발, 장식 그림자, 같은 카드 반복, 기계적 문구) | 2026-11-08 "ai smell" |
| Q10 | 글자 겹침·잘림이 0인가(DOM 실측) | F19, F21 |
| Q11 | 패턴 대장의 어떤 패턴과도 같지 않은가. 선 한두 개 추가, 색 변경, 테두리 추가는 다른 패턴이 아니다 | 2026-11-08 디자인 유사성 검사 |
| Q12 | 일부러 약하게 만든 후보가 아닌가(그 항목에서 이길 수 있는 설계인가) | 2026-11-08 허수아비 후보 지적 |

## 2. 패턴 대장

### 2-2. 이번에 새로 쓰는 패턴(각 한 번만)

Phase 5에서 후보를 만들 때마다 여기에 올린다. 한 줄 = 그림 요소 + 배치 + 무엇을 무엇에 대응시켰는지.

| 번호 | 항목 | 패턴 |
|---|---|---|
| N01 | 공부 시간 S1 | 폭포: 평소 한 주 기둥에서 날짜마다 늘고 준 만큼 계단을 쌓아 이번 주 기둥에 닿음(세로 = 시간) |
| N02 | 공부 시간 S2 | 학습관 산점도: 가로 = 평소 하루, 세로 = 이번 주 하루, 대각선 = 평소만큼, 감소 기준 아래 영역 음영, 150명 회색 + 이 학생 |
| N03 | 공부 시간 S3 | 개인 분포 쌓기: 35일 하루 공부 시간을 30분·1시간 칸에 하루 한 조각씩 쌓은 분포, 최근 7일 조각만 색, 결석은 왼쪽 따로 |
| N04 | 공부 시간 S4 | 주별 쌓기 기둥: 5주 기둥, 기둥 안 날짜 조각 높이 = 그날 공부 시간 |
| N05 | 공부 시간 S5 | 누적 계단: 최근 7일 누적 굵은 계단 + 그 전 4주의 같은 순서 누적 가는 계단 넷 |
| N06 | 입실 시각 T1 | 하루 시간표: 날짜 줄 × 하루 시각, 입실에서 공부 길이만큼 막대, 막대 안 틈 = 사진 인식 비몰입 구간, 세로 홈 = 같은 요일 평소 입실 |
| N07 | 입실 시각 T2 | 요일 줄 눈금: 요일마다 한 줄, 같은 요일 5주 입실을 시각 축 세로 눈금으로(지난 4주 회색, 최근 굵게) |
| N08 | 입실 시각 T3 | 평행 축: 입실 시각 → 공부 시간 → 비몰입 시간 세 축을 날마다 한 줄로 이음 |
| N09 | 입실 시각 T4 | 이어진 늦음 받침: 35일 입실 시각 점(세로 = 시각) + 기준만큼 늦은 날이 이어진 길이의 받침 막대 |
| N10 | 입실 시각 T5 | 이른 순 사다리: 35일 입실을 이른 날부터 줄 세운 내림 막대, 최근 7일만 색 |
| N11 | 계획 대비 P1 | 과목 흐름: 왼쪽 계획 기둥 → 오른쪽 실제 기둥, 과목별 띠 굵기 = 시간 |
| N12 | 계획 대비 P2 | 계획 넓이 안의 실제: 과목 사각형 넓이 = 계획, 같은 비율로 줄인 안쪽 사각형 넓이 = 실제 |
| N13 | 계획 대비 P3 | 과목 방사형: 과목 축, 바깥 고리 = 계획 100%, 꼭짓점 = 실제/계획 |
| N14 | 계획 대비 P4 | 계획 그림자: 35일 날짜 순서로 계획 시간 연한 면 위에 실제 시간 진한 면 |
| N15 | 계획 대비 P5 | 마주 보기: 가운데 과목 이름, 왼쪽 계획 시간, 오른쪽 실제 시간 |
| N16 | 사진 관찰 V1 | 사건 필름: 긴 비몰입 4건, 줄마다 근거 사진 3장 + 같은 분 눈금의 사건 길이 막대와 촬영 시점 눈금 |
| N17 | 사진 관찰 V2 | 그림 쌓기: 35일 날짜마다 비몰입 한 건 = 휴대폰·엎드린 사람·빈 의자 그림 하나 |
| N18 | 사진 관찰 V3 | 크기 원 격자: 종류 3줄 × 35일, 원 넓이 = 그날 그 종류 비몰입 시간, 공부 감소일 빨강 |
| N19 | 사진 관찰 V4 | 시간대 겹침: 종류 3줄 × 하루 시각, 35일 비몰입 구간을 반투명으로 겹침 |
| N20 | 사진 관찰 V5 | 종류별 쌓인 면: 35일 비몰입 분을 종류별로 쌓은 면, 이름은 가장 두꺼운 곳에 직접 |
