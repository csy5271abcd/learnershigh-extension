# 지표별 표현 (5판, 시각 표현 우선)

작성 2026-11-07. 사용자 지적: 지표마다 맞는 표현을 고민하라고 했는데 막대·꺾은선과 1차원 표기에 머물렀고, 다량(150명)·극단 데이터에 약하며, 텍스트를 우겨넣었다. 텍스트는 최후 수단이다. 이 문서가 `plan-v5.md` 3장 P5를 대체하고, 네 안은 이 표현을 공통으로 쓴다(안마다 다른 것은 화면 구조이지 지표 표현이 아니다).

근거: dataviz 스킬(`choosing-a-form`, `marks-and-anatomy`, `anti-patterns`) — 숫자를 모든 점에 쓰지 않고 선택적으로만 직접 표기, 정확한 값은 마우스·키보드 초점 안내(툴팁)와 선택한 대상에서, 2개 이상 계열이면 짧은 범례를 둔다. 4판의 "범례 금지 → 모든 값에 글자"는 이 원칙과 반대였다.

## 1. 원칙

1. **모양이 먼저, 숫자는 필요한 곳에만.** 기본 화면의 숫자는 (a) 머리 숫자(지표당 1–2개), (b) 극단값·선택한 학생의 값뿐이다. 나머지 값은 안내(hover·focus)와 학생 선택 후 상세에서 본다.
2. **150명을 점 하나씩.** 평균 하나로 줄이지 않고 학생마다 점 하나를 같은 축에 놓아(분포 점 그림) 다수와 극단이 함께 보이게 한다. 극단값은 축을 늘리지 않고 끝에 모아 "그 너머"로 표시하고, 그 학생만 이름을 붙인다.
3. **비교는 본인 평소 대비.** 학생마다 평소가 달라 절대값을 나란히 그리지 않는다(기존 조사 결론 유지). 0(평소)을 기준선으로 위·아래로 퍼진다.
4. **관리 대상은 강조, 나머지는 회색.** 사유가 있는 학생 점만 진한 색, 정상 학생은 연한 회색. 색 하나 + 회색이라 범례가 필요 없다(제목이 "주황 점 = 상담 필요"를 대신하지 않도록, 강조 학생은 이름이 붙는다).
5. **범례는 짧게 허용.** 두 가지 이상 상태를 한 칸에 겹칠 때만, 그래프 바로 위 한 줄, 3항목 이하. 형식 설명("(시간:분)")·계산 설명은 쓰지 않는다.
6. **글자량 관문.** 같은 상태끼리 기존 화면보다 보이는 글자가 적어야 한다(측정기 `text`). 정확값 요구는 글자 추가가 아니라 안내·선택 상세로 해결한다.

## 2. 학습관(150명) 표현

| 지표 | 데이터 성격 | 관리자의 판단 | 표현 | 다량·극단 처리 | 기본 화면의 글자 |
|---|---|---|---|---|---|
| 결석·계획 미제출 | 학생×날짜 범주(입실·결석·예정 없음·기록 없음, 제출·미제출) | 누가 이어서 빠지는가, 같은 요일 반복인가, 날짜별 규모 | **출결 행렬**: 결석이 1일 이상 있는 학생만 행(약 30명), 7일 열. 결석 = 채운 칸, 미제출 = 칸 아래 짧은 선(범례 2항목). 연속 길이 순 정렬. 열 머리에 그날 결석 인원 | 결석 없는 120명은 행으로 그리지 않고 "결석 없음 120명" 한 줄. 4일 이상 연속 행은 이름 강조 | 학생 이름(식별에 필요), 열 머리 인원 |
| 학습 시간 | 학생별 평소 대비 % (연속값, 꼬리 김) | 학습관 전체가 줄었나, 누가 크게 줄었나, 정상 개인 차이와 구분 | **날짜별 분포 점 그림**(7열, 열마다 학생 점이 겹치지 않게 퍼짐). 0 기준선, 가운데 값 짧은 가로선, 가운데 절반은 옅은 띠 | 축 ±100%에서 자르고 넘는 학생은 끝에 "▲" 묶음(개수) | 열마다 가운데 값 1개, 기준(설정의 감소 %) 아래로 크게 떨어진 학생 이름(최대 3명/열, 나머지는 개수) |
| 입실 시각 | 학생별 평소 대비 분 | 늦어짐이 학습관 전체인가 일부인가 | 같은 분포 점 그림(분 단위) | ±120분에서 자름 | 열마다 가운데 값, 설정 기준(분) 넘은 학생 이름 최대 3명 |
| 비전(예시) | 학생별 사진 비율(축 4개 독립, 분모 다름) | 휴대폰 사용 관찰이 많은 학생이 있나 | 축 4개 작은 그림(같은 모양 4개), 각 7열 분포 점. 점 크기 = 분석 장수(작은 표본은 작은 점으로 신뢰가 낮음을 보임) | 분석 10장 미만은 빈 원 | 축 이름, 열마다 사진 기준 비율 1개 |

학생 점을 누르면 그 학생 상세가 열린다(안마다 열리는 방식이 다름). 점에 마우스·초점을 두면 "이름 · 실제 3시간 8분 · 평소 3시간 13분 · −3%" 안내.

## 3. 학생 한 명 표현

| 지표 | 표현 | 기본 화면의 글자 |
|---|---|---|
| 머리 | 머리 숫자 3개(7일 학습 vs 평소 주, 입실 일수, 진행률)와 사유 | 숫자 3개, 사유 칩 |
| 출결·제출 7일 | 칸 7개 한 줄(결석 = 채움, 예정 없음 = 빗금, 기록 없음 = 점선 테두리), 미제출은 칸 아래 선. 범례 한 줄 | 날짜 |
| 학습 시간 7일 | **아령 그림**(날짜마다 평소 ○ – 실제 ●, 세로 시간축). 줄어든 날은 선이 주황 | 7일 합계만 머리 숫자에. 날짜별 값은 안내 |
| 입실 시각 7일 | 아령 그림(시각 축, 평소 ○ → 실제 ●) | 설정 기준보다 늦은 날만 "+62분" |
| 진행률 | 날짜별 진척 막대(계획 길이 안에 실제 채움) | 7일 진행률만 |
| 과목 비중 | 아령(계획 % ○ → 실제 % ●), 차이 10%p 이상 과목만 숫자 | 해당 과목만 |
| 35일 출결 | 달력 칸(월요일 시작, 결석 = 채움). 같은 요일 반복이면 그 열 머리 강조 | 날짜 숫자 없음(안내로) |
| 비전(예시) | 축 4개 × 7일 작은 막대(사진 비율, 판단 불가는 빗금 나머지), 분석 0장·사진 없음은 빈 칸 | 축 이름, 7일 합 비율 |

## 4. 학생 고르기 명단

명단은 고르는 수단이므로 이름·반·상태·대표 사유 1개(나머지는 "+2")만 둔다. 7일 값·그림은 넣지 않는다(4판 "중간 어딘가" 방지). 사유별 인원은 사유 필터 버튼에.

## 5. 확인 방법

- 측정기 `text`(같은 상태끼리 기존 화면 이하), `firstScreenText`.
- 극단 반례: 학습 +250%, 입실 +300분, 결석 7일, 분석 1장 학생을 합성해 그림이 깨지지 않는지(축 늘어남·겹침·잘림 없음) 모델 테스트와 캡처로 확인.
- 다량 반례: 150명 같은 값(점 겹침) — 퍼짐 배치로 점이 모두 보이는지.
