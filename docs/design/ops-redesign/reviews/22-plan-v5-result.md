## 4. C·D 승인 여부

### C — 조건부 승인

대상 학생을 중복 없이 고르고, 사유와 근거를 확인한 뒤, 넓은 개인 상세에서 기록하고 서버의 다음 확인 상태로 돌아오는 구조는 핵심 요구와 연결된다. 모든 학생에게 상세 그림을 반복하거나 화면 전용 업무 완료 상태를 만드는 것보다 기존 모델과의 중복·운영 부담이 적다. 정상 학생도 전체 학생 탭에 남는다.

학습관은 개인 변화의 분포와 날짜 변화를 함께 보므로 B의 시간 그래프+팝업과 별도 안으로 성립할 가능성이 있다. **현재 C보다 명백히 나은 대체 구조를 새로 요구할 근거는 없다.** 효과는 Q18·Q19와 실제 흐름으로 확인할 가설이다.

조건은 기존 1.5단계다. 다섯 지표 요약을 식별하고, 결과 150행을 연 뒤에도 다른 지표로 가려고 그 목록을 지나지 않으며, 서랍에 넓은 폭과 한 곳 스크롤을 제공하는 배치가 확인돼야 한다. 그림이 실패하면 C를 고쳐 재검토하고 구현한다. 서랍이라는 이름만으로 B와의 구분을 통과시키지 않는다.

### D — 조건부 승인

학습관 요약을 먼저 보고 선택 지표에서 학생으로 내려간 뒤 별도 개인 화면에서 종합하는 구조는 전체/개인 목적을 분리한다. 정상·기록 부족 학생의 명부 진입과 항상 보이는 이름 검색도 있어 문제 학생만 남기는 도구로 축소되지 않는다. **명백히 더 나은 대체 D를 요구할 근거는 없다.** 이 구조가 과업 성과에서 최고라는 증거는 아직 없다.

조건은 기존 1.5단계에서 다섯 요약의 날짜·값이 읽히고, 상세 결과가 요약 접근을 막지 않는지 확인하는 것이다. 작은 차트를 이유로 날짜나 단위를 지우면 실패다. 이후 구현에서는 학생 화면 복귀 시 지표·날짜·분포 구간·비교·검색·제외·스크롤 복원이 실제로 성립해야 한다.

**두 안의 ‘조건부 승인’은 구조 채택 허용과 이미 계획된 배치 관문을 뜻한다. R01·R02 수정 요구가 남았다는 뜻도, 배치 관문 없이 즉시 화면을 구현해도 된다는 뜻도 아니다.**

## 5. 통과 여부

**계획 통과: 94점 ≥ 85점, 필수 지적 0건.** 0단계를 통과시키고 1단계 준비 작업을 승인한다. C·D를 포함한 네 안은 1.5단계 검토 후 구현하며, 완료는 네 안 각각 최종 93점 이상·목적 관문 통과·필수 위반 0일 때뿐이다. 이번 점수를 구현 완료 점수로 사용하지 않는다.

## 6. 개선 제안 — 우선순위 순
