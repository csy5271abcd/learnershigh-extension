## 사용자 요구 요약
학생별은 한 학생씩 넓게 상세히, 학습관별은 학습관 전체 지표가 잘 보이게. 4판은 학생 명부가 "그 사이 어딘가"였고 학습관 탭 의미가 사라졌다. 스크롤바 2개 금지, 넉넉한 공간에 우겨넣기 금지, 범례·형식 설명 없이 읽혀야 함, 비전 AI 포함, 시안 4개 구조가 서로 달라야 함. 핵심: 관리자가 이해하기 쉬운 흐름, 학습관 전체 지표와 학생별 지표를 각각 쉽게 식별.

## 판정
배치도는 자리 표시 값을 쓴 구조 그림이다. 숫자 정확성이나 시각 다듬기가 아니라 구조를 본다.
1. 안마다 P1(학생 상세 폭 70% 이상, 명부가 상세 대신 안 함), P2(1600×900 첫 화면에 4지표 + 비전, 결과를 연 뒤 다른 지표로 가는 길이 학생 목록을 지나지 않음), P3(일반 화면 내부 스크롤 없음, 모달·서랍은 배경 잠금 + 한 곳), P5(범례 줄·해독 문구 없음, 값·범위에 직접 글자), P6(학생·학습관 양쪽 비전), P7(구조 축 2개 이상 차이)이 그림에서 성립하는가. 각 그림에 `care-p34-probe.mjs`를 직접 돌려 봐도 된다.
2. C 조건: 다섯 지표 요약 식별, 결과 150행을 연 뒤에도 다른 지표로 가려고 목록을 지나지 않음, 서랍 넓은 폭·한 곳 스크롤.
3. D 조건: 다섯 요약의 날짜·값이 읽힘, 상세 결과가 요약 접근을 막지 않음, 학생 화면 복귀 상태 표시.
4. 구현 전에 고칠 구조 문제(있다면)와, 구현 단계에서 지켜야 할 주의(통과를 막지 않는 것)를 나눠라.
