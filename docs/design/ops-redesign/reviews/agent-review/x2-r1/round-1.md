## 화면에서 고치지 않은 것(의존 사항)

- 관리 기준 대화상자의 항목 이름이 서버 사유 이름과 다르다(결석↔미입실 등, 분석가 A2). 기존 공용 대화상자라 X′에서 이름만 바꾸지 않았다. 서버 사유 이름으로 맞출지 사용자 확인 필요.
- 상담 저장 흐름(오류 문구가 남음, 기록자 없이 저장, 다음 확인일 미리 선택, 한 번 저장에 두 줄, '기록 오류' 뜻, 사용자 3)은 기존 상담 컴포넌트(`CounselForm`)의 동작이다. 지시대로 기존 컴포넌트만 써서 손대지 않았다.
- 같은 학생 숫자가 화면마다 다르다(사용자 4): 상담 기록의 수치는 서버가 관리를 시작한 날 저장한 값이고, 겹창은 오늘 기준 최근 7일 값이다. 날짜를 함께 보여 주는지는 상담 기록 화면(기존) 쪽 문제.
- 서버 사유가 둘뿐인 문가영(결석한 날을 계획 미제출로도 셈)은 서버 쪽 문제(인계 문서 5장).
