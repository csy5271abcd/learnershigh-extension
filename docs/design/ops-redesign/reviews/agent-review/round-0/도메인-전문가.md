### 도메인 전문가 검토 요약
(그래도 되는 것) 세 시안 모두 판정 빨강을 서버 사유에만 쓰려는 방향은 맞고, 종일형 변지호(하루 12시간)와 주 2일 방시우의 '예정 없음'을 결석으로 만들지 않았다. Z′ 상세의 5주 결석 막대는 구서아의 5주 결석을 실제로 드러낸다.

- 기준 시점: API asOf 2026-10-27, 강남점(demo_large) 160명. 관리 기준(서버 settings): 미입실 1일, 계획 미제출 2일, 공부 감소 30%, 달성 60%, 입실 60분, 최소 유효일 3일.
- 확인 방법: Playwright 1600×1000 라이트(전체·학생 12명 상세), 1024 다크, Z′ 학습관 탭. API(`/metrics`, `/board`, `/settings`)와 감독관 이벤트(`/supervisor-api/students/{id}/events`)를 직접 대조.
- 캡처·스크립트: `round-0/도메인-전문가/` (`x-<이름>.png`, `y-<이름>.png`, `z2-<이름>.png`, `crop-*.png`, `z2-branch-1600-light.png`, `*-1024-dark.png`, `detail-text.json`)
- 범위 밖: 키보드·대비 계산은 이 역할에서 하지 않았다(다른 역할 담당). 1280 폭은 찍지 않았다. 1024 다크에서는 세 시안 모두 가로 넘침이 0px였다.
