## 서버 쪽(화면만으로 못 고침, 의존 사항으로 보고)

- C1 사유 전부 겹치는 문가영의 서버 사유가 미입실·계획 미제출 둘뿐(입실 +110분, 계획 18%는 사유 없음).
- C2 결석한 날을 계획 미제출로도 세어 사실 하나가 사유 두 개가 됨. 결석한 날에도 계획 제출을 요구하는지 운영 정책 확인 필요.
- C3 계획 기능을 쓰지 않는 학생(염태윤)을 계획 미제출로 판정.
