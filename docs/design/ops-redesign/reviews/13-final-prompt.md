## 사용자 요구
운영자가 보자마자 관리할 학생과 이유를 알고 바로 쓸 수 있어야 한다. 기존 지표·기능을 줄이지 않는다. 텍스트 감소, 펼치기·접기 등 복잡성 감소, 과도한 스크롤·과밀 금지, 지표 의미 보존(결석은 횟수와 날짜 패턴 등). 학습관별은 다량 학생에 부적합했고 개인별은 한눈에 보기 어려웠다.
추가 요구(2026-11-07): 표준 용어, 한영 혼용·어색한 표현 금지, 같은 개념은 한 용어. 무의미한 나열·열거, 강조할 필요 없는 강조, 과도한 반복, 관리자에게 필요 없는 산출 기준·메타 설명(예: "학생 대상 60%에 대한 4주간 비교 분포")을 화면에 두지 않는다. 이 요구로 화면에서 뺀 것은 `contract-changes.md`에 기록돼 있어야 하고, 판단에 필요한 정보 자체가 사라졌다면 기능 누락으로 본다.
