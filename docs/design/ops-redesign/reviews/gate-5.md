# 학생 케어 시안 X · Y · Z′ — 5단계 자체 검토 게이트

시안을 고칠 때마다 이 다섯 게이트를 차례로 통과시킨다. 한 게이트에서 지적이 나오면 고치고 **1단계부터 다시** 돈다. 다섯 게이트 모두 지적 0건이 될 때까지 반복한다.

각 게이트는 정해진 사람(페르소나)의 눈으로 본다. 검토는 코드가 아니라 **화면 캡처**(1600·1280·1024 × 라이트·다크)를 보고 한다. 지적은 "어디(시안·학생·폭·테마·구성 요소) / 무엇이 / 왜 문제 / 고칠 방향" 한 줄씩 남긴다.

색과 두께는 한 값으로 정하지 않는다. 후보 3–4개를 같은 데이터로 나란히 그려(`tune.mjs` 비교 시트) 고르고, 고른 값과 이유를 아래 기록 표에 남긴다.

## 1단계 · 데이터 검토자

> 너는 학생 케어 서버와 이미지 인식 서버의 판정 규칙을 아는 데이터 검토자다. 화면의 숫자·막대·빨강이 서버 값과 같은지만 본다. 디자인 취향은 말하지 않는다.

- 칸·막대·말풍선의 값이 같은 학생의 서버 값(signals, week, days, 이벤트 수)과 같은가
- 빨강은 서버 사유가 있고 지금 값이 같은 기준을 넘을 때만인가(비몰입은 빨강 없음)
- 단위가 빠지거나 두 번 붙지 않았나(Y는 열 머리에 한 번)
- 값 없음(–, 기록 없음)과 0이 구분되는가, 연결 실패와 빈 데이터가 구분되는가
- 사진 단계(처음 감지·중간·확정)가 서버가 고른 근거와 같은가

## 2단계 · 주니어 디자이너

> 너는 픽셀을 꼼꼼히 보는 2년 차 UI 디자이너다. 겹침·잘림·정렬·간격만 본다.

- 글자끼리, 글자와 선·막대가 겹치거나 닿지 않는가(측정 0건 + 눈으로)
- 잘린 글자, 칸 밖으로 나간 글자, 말줄임이 의미를 잃는 곳이 없는가
- 같은 종류 요소의 시작선·높이·간격이 맞는가(막대 시작, 값 글자 기준선, 카드 안쪽 여백)
- 글자 크기 단계가 3개 이하인가(제목·본문·눈금)

## 3단계 · 시니어 디자이너

> 너는 대시보드를 10년 넘게 만든 시니어 디자이너다. 위계·색감·두께·여백과 시안의 존재 이유를 본다. Stephen Few, Tufte 기준으로 잉크 낭비와 잡음을 싫어한다.

- 위계: 데이터 > 비교 기준(평소·중앙·계획) > 격자·축이 색 진하기와 두께로 바로 읽히는가
- 색감: 파랑·빨강·회색이 같은 계열 밝기로 어울리는가, 다크에서 탁하거나 형광처럼 튀지 않는가
- 두께: 막대·선·눈금이 화면 크기에 비해 무겁거나 실처럼 가늘지 않은가(후보 비교로 고름)
- 여백: 빈 반쪽·텅 빈 그림이 없고, 우겨넣지도 않았는가
- 범례·칸 안 글자 상자·± 표기·AI 같은 꾸밈 문구가 없는가
- 세 시안이 서로 다른 이유로 존재하는가(X 원본 콘솔, Y 학생끼리 비교, Z′ 사유 중심 흐름). 같은 그림을 되풀이하지 않는가

## 4단계 · 사용자(학습관 관리 선생님)

> 너는 학생 150명을 맡은 학습관 관리 선생님이다. 오후 수업 전 10분 안에 오늘 연락할 학생을 고르고 상담 기록까지 남겨야 한다. 차트 용어는 모른다.

- 3초 안에 "누가, 왜, 얼마나"가 보이는가
- 사유 이름이 다른 화면(명부·거르기·상세)과 같은 말인가
- 상담 기록까지 몇 번 눌러야 하는가, 돌아가기가 쉬운가
- 뜻을 모를 말(중앙, 4주 평균 등)이 설명 없이 나오지 않는가
- 사진이 무슨 장면인지 바로 알 수 있는가

## 5단계 · 접근성·반응형 검토자

> 너는 접근성(WCAG 2.2 AA)과 반응형을 맡은 프런트엔드 검토자다.

- 1600·1280·1024에서 가로 넘침·접힘 오류가 없는가
- 라이트·다크 모두 글자 대비 4.5:1(작은 글자), 그림 요소 3:1 이상인가 — **눈으로 보지 말고 잰다**: `cchk.mjs`(그림 요소, 격자·축·바탕 띠 제외)와 `tchk.mjs`(글자) 미달 0건. 학생은 결석이 있는 학생·없는 학생 둘 다
- 검토 화면은 라이트와 다크를 한 장에 나란히 놓고 본다(한쪽만 고치고 다른 쪽을 놓치지 않게)
- 키보드로 줄 펼치기·정렬·탭·겹창 닫기가 되는가, 초점이 보이는가
- 말풍선 값이 화면 밖으로 나가지 않는가, 마우스 없이도 같은 값을 읽을 수 있는가(aria-label)
