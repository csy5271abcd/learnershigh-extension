# 학생 케어 최종 시안 X·Y·Z′ 디자이너 검토 지침

## 1. 요구사항(사용자가 정한 것)

- 대상: 학습관 관리자(원장·관리 교사)가 매일 "오늘 관리가 필요한 학생"을 찾고, 왜 필요한지 확인하고, 상담을 남기는 화면.
- 지표: 출결·계획 제출(최근 7일 글자 칸, 채택), 공부 시간, 입실 시각, 계획 대비 실제(날짜별·과목별), 사진 관찰(이미지 인식 서버의 비몰입: 휴대폰 사용·엎드림·자리 비움, 건수 + 근거 사진 3장 기록).
- 기간: 일간(최근 7일, 날짜별)과 주간(최근 5주, 주별)을 바꿔 본다. 같은 꼴의 그림에서 칸 수만 7 ↔ 5.
- 시안 성격
  - X: 원본 서비스(러너스하이 StudyLab 관리 콘솔, Metronic 색·Spoqa 글꼴) 스타일. 왼쪽 학생 표 + 오른쪽 상세 탭.
  - Y: 데이터 중심. 학생 전원 표, 기준을 넘은 학생 거르기, 열 정렬, 줄을 펼치면 상세.
  - Z′: 깔끔한 화면 구성·사용 편의 우선. 오늘 명부(사유 + 값) → 겹창 상세 → 상담. 학습관 탭, 관리 이력 탭.
- 판정(관리 사유, 기준)은 서버 그대로. 화면은 보여 주기만 한다.

## 2. 사용자가 반복해서 지적한 것(어기면 바로 기각)

- 상자 안에 글자·%·± 를 채우는 표시 금지(출결·계획 제출 칸만 예외).
- 텍스트 나열은 표시법이 아니다. 텍스트는 마지막 수단.
- 범례가 있어야 읽히는 그림 금지. 이름은 그림에 직접.
- 지표의 의미가 사라지면 안 된다: 단위, 비교 기준(평소·지난 주), 날짜 정보, 결석 표시.
- 겹친 막대 금지(나란히 막대). 축 없는 선 금지. 모양 기호(○●✓✕) 금지.
- 글자가 글자·선·막대와 겹치거나 잘리면 안 된다. 글자 위치가 어색하면 안 된다.
- 의미 없는 빈 공간(공허함)도, 우겨넣은 촘촘함도 안 된다.
- 같은 말은 같은 용어(서버 사유 이름과 화면 이름 일치), 한영 혼용 금지, 반복·메타 설명 금지.
- 경계가 모호하거나 AI가 만든 티(어색한 장식, 의미 없는 색)도 지적 대상.

## 3. 검토 관점(시니어 프로덕트 디자이너)

- Nielsen 사용성 10원칙(상태 보이기, 현실 용어, 일관성, 오류 예방, 기억보다 알아보기, 효율, 미니멀, 오류 회복, 도움말).
- 대시보드 점검: 목적에 맞는 그림인가, 비교 맥락이 있는가, 값이 직접 적혀 있는가, 색이 절제되었는가, 한 화면에서 핵심이 보이는가.
- 시각 위계: 제목·값·보조 글자 크기와 굵기, 정렬선, 간격 리듬, 카드 경계.
- 상호작용: 마우스 올림 정확값, 일간·주간 바꾸기, 정렬·거르기, 학생 이동, 겹창 닫기, 키보드 초점.
- 반응형: 1600·1280·1024 폭, 라이트·다크.

## 4. 검토 단위(작은 것부터 빠짐없이)

1. 데이터 한 줄: 막대 하나, 점 하나, 값 글자 하나, 축 눈금, 날짜 글자, 결석 표시.
2. 그림 하나(구성 요소): 제목, 기간 바꾸기, 이름표, 기준선, 빈 상태.
3. 칸·카드: 여백, 정렬, 높이 맞춤.
4. 화면 전체: 흐름, 위계, 밀도, 시안 성격에 맞는지.
