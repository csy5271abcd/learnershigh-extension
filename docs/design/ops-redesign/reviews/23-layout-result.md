# 학생 케어 A–D 배치 관문 검토

검토일: 2026-11-07. 대상: plan-v5 6장 1.5단계. **전체 관문 불통과: 필수 수정 4건. A는 배치 수준 통과, B·C·D는 재검토가 필요하다. 네 안의 구현 착수를 승인하지 않는다.** 사용자 추가 답변은 요구하지 않는다.

## 1. 범위와 판정 방법

계획 3장 P1–P8·판정 상태, 4장 구조, 6장 관문, 22차 결과의 C·D 조건과 개선 제안 1, 배치도 README·생성 코드를 대조했다. PNG는 1600/1280×900 **30장과 전체 길이 보조 그림 6장**을 확인했다. 아래 그림 이름의 경로는 모두 `../wireframes-v5/`다.

자리 표시 숫자의 정확성·표본 합계·실제 데이터 성과는 채점하지 않았다. 단, 값·날짜가 들어갈 공간의 부재, 화면 밖으로 나가는 지표, 긴 명부가 이동 수단을 없애는 현상은 배치 문제로 판단했다. 정적 그림에 없는 클릭·저장·복원을 동작한다고 가정하지 않았다. 통과는 **배치 수준** 판정이며 제품 기능·과업 시험·최종 93점 승인이 아니다.

생성기를 그대로 실행하면 원본 그림을 덮어쓰므로 실행하지 않았다. 검토용 [inspect.mjs](23-evidence/inspect.mjs)가 생성 코드에서 정적 HTML 상태 문자열만 읽어 메모리에서 재현했다. 네트워크 요청은 전부 차단했다. 이 재현은 그림의 스크롤 배치를 확인하는 보조 증거이며 인터랙션 구현 검증이 아니다. 기존 `/student-care`·`/student-care/ops`는 이번에 접속하지 않았다.

| ID | 대상·결함 | 최소 수정과 재검토 통과 조건 |
