# 학생 케어 사용 안내 (운영자용)

학습관리 › 학생 케어 개선안 화면은 관리가 필요한 학생을 찾고 이유를 확인하고 상담 기록을 남기는 화면이다. 학생 기록은 최근 7일을 보고, "평소"는 그 전 4주의 같은 요일 기록이다.

## 매일 쓰는 순서

1. 상단에서 지점을 고른다. 첫 줄에 전체 인원과 상담 필요·관리 중 인원이 나온다.
2. 학생별 탭의 명부는 확인일이 된 관리 학생 → 상담 필요 → 관리 중 → 기록 부족 → 이상 없음 순이다. 행 왼쪽에 주황 선이 있는 학생이 오늘 볼 학생이고, 사유 칸에 이유가 짧게 적혀 있다.
3. 학생 행을 누르면 오른쪽 상세가 그 학생으로 바뀐다. 명부는 그대로 남는다. 명부 위 선택 상자로 "사유: 결석"처럼 사유별 학생만 모아 볼 수 있다. 좁은 화면(태블릿·휴대폰)에서는 학생을 누르면 상세만 보이고, "← 명부로"를 누르면 그 학생 줄로 돌아온다.
4. 상세 아래 상담 기록에서 방법·내용·결과를 고르고 저장한다. "계속 관리"를 고르면 다음 확인일을 정한다. 저장하면 학생 상태가 관리 중으로 바뀌고 다음 확인일이 되면 명부 맨 위에 다시 올라온다.

## 명부 한 줄 읽기

| 칸 | 뜻 |
|---|---|
| 이름 · 반 | 반은 짧게 쓴다(고3 A반 → 3A) |
| 사유 | 서버가 판정한 상담 사유. 예) `결석 4일 연속·미제출`은 최근 7일 중 등원 예정일 4일을 이어서 결석했고 그날 계획도 내지 않았다는 뜻. `학습 −9시간 45분 (−55%)`은 최근 7일 학습 시간이 평소 주보다 그만큼 적다는 뜻 |
| 점선 칩 | 서버 판정이 아니라 날짜에서 계산한 참고 표시. 예) `목요일 결석 5/5번`은 최근 5주 목요일 등원 예정일 5번 모두 결석 |
| 7일 띠 | 위 줄은 출결(회색 입실, 주황 결석, 빈 칸 예정 없음, 점선 기록 없음), 아래 줄은 계획 제출(주황 미제출). 머리글 요일과 열이 맞는다 |
| 학습 시간 | 막대가 최근 7일, 세로선이 평소 주. 모든 학생이 같은 축이라 막대 길이로 바로 비교된다. 숫자는 "7일 / 평소 주" 시간 |
| 진행률 | 최근 7일 실제 학습 ÷ 계획. 100%를 넘을 수 있다 |

## 학생 상세

맨 위 한 줄에 7일 합계, 평소 주, 입실·제출 일수, 진행률이 있다. 그 아래 7일 표는 날짜 열을 함께 쓰므로 "결석한 날 → 학습 막대 없음 → 입실 시각 없음"이 세로로 읽힌다. 학습은 실제와 평소(같은 요일)를, 입실은 시각·평소·차이를, 진행률은 비율과 실제/계획 시간을 쓴다. 35일 출결 달력은 주가 줄, 요일이 열이라 연속 결석은 가로로, 같은 요일 반복 결석은 세로로 보인다. 과목 비중은 계획과 실제 비율이며 사유가 된 과목은 시간도 적는다.

## 학습관별 탭

지점 전체를 날짜별로 본다. 결석(결석 / 등원 예정), 학습 시간(입실한 학생 평균과 평소 대비 중앙값), 입실 시각(평소 대비 중앙값), 계획 제출률이 같은 날짜 열에 있다. 칸을 누르면 그 날짜·지표의 학생 전원이 실제·평소·차이와 함께 아래에 나온다. 지표 이름을 누르면 7일 동안 기준을 넘은 학생이 나온다. 이름을 누르면 학생별 탭의 상세로 간다. 목록의 "비교"를 누르면 최대 3명의 7일 값이 같은 날짜 열의 표로 아래에 모인다. 특정 학생(예: 장기 결석 중인 학생)을 지점 대표값에서 빼려면 "집계에서 제외"에 이름을 넣는다. 지점 대표값 계산에서만 빠지고 학생 기록과 상담 상태는 바뀌지 않는다.

### 화면 값의 기준

화면에는 산출 기준을 적지 않았다. 필요할 때 여기서 확인한다.

- 평소: 이전 4주의 같은 요일 값. "평소 주"는 이전 4주 학습 시간 합 ÷ 4.
- 결석 "연속": 등원 예정일만 이어서 센다. 예정 없는 날은 연속을 끊지 않고, 기록 없는 날은 끊는다. 연속이 아니면 "결석 N일"만 쓴다.
- 명부 띠에서 "기록 없음" 칸이 있는 학생의 7일 학습 시간은 기록 있는 날만 더한 값이다. 상세 숫자 줄에 "(기록 n/7일)"로 나온다.
- 학습관 학습 시간 칸: 입실한 학생 평균, 아래 작은 숫자는 학생별 평소 대비 변화의 중앙값.
- 같은 요일 결석(점선 칩): 35일 중 같은 요일에 4번 이상 결석한 학생. 서버 판정이 아닌 참고 표시라 상담 필요 여부에 영향을 주지 않는다. 판정에 넣으려면 관리 기준 설정의 결석 기준을 조정한다.

## 관리 기준 설정

상단 톱니 버튼에서 지점별 판정 기준(결석 일수, 계획 미제출 일수, 학습 감소 %, 진행률 %, 과목 비중 차이, 입실 지연 분, 최소 기록 일수, 재판정 대기 일수)을 바꾼다. 저장하면 명부의 상담 필요 학생과 학습관 탭의 기준선이 새 값으로 다시 계산된다.

## 용어

| 용어 | 뜻 |
|---|---|
| 상담 필요 | 판정 기준에 걸렸고 아직 관리 기록이 없는 학생 |
| 관리 중 | 상담을 기록하고 계속 관리 중인 학생. 사유는 관리를 시작할 때의 사유 |
| 확인일 | 관리 중 학생의 다음 확인일이 된 상태. 재확인 결과를 기록한다 |
| 기록 부족 | 최근 기록이 적어 판정을 미룬 학생 |
| 예정 없음 | 그날 등원 예정이 없음. 결석으로 세지 않는다 |
| 기록 없음 | 그날 원본 기록이 없음. 결석이나 0분과 다르다 |
