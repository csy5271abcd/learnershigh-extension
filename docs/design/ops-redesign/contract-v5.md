# 피드백 계약과 5판(A–D)의 관계

기존 `student-care-feedback-contract.md`(F01–F24)와 `student-care-feedback-gate-2026-10-28.md`(G01–G54) 항목을 5판 결정(2026-11-07)에 따라 유지·대체·해당 없음으로 나눈다. 4판용 `contract-changes.md`의 명부 띠·고정 상세 정당화는 5판에 쓰지 않는다. 과거 문서의 체크 표시를 5판 통과 증거로 옮기지 않는다. 아래에 없는 항목은 네 안 모두 **유지**이며 안마다 Codex 최종 채점에서 다시 확인한다. G13(학습관 총 학습량을 주요 성과 지표로 쓰지 않고 평균 학습 시간과 개인 비교를 보존)은 유지 항목이다: 평균과 개인 변화 분포(중앙값·범위)는 다른 값이며 둘 다 보인다. 2026-11-07 F01–F24·G01–G54를 다시 대조해 위 표 외에 바뀌는 항목이 없음을 확인했다(대조 기준: 5판 P1–P8과 4장 안별 구조).
