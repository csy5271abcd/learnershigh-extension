## 화면 계산과 서버 판정의 구분

- 결석 신호(`CONSECUTIVE_ABSENCE`)는 서버에서 연속이 아니라 최근 7일 예정일 결석 횟수다. 칩의 "연속"은 화면이 날짜에서 계산한다(연속이 아니면 붙이지 않는다). 예정 없는 날은 연속을 끊지 않고 기록 없음은 끊는다.
- "목요일 결석 5/5번"은 서버 판정이 아니라 35일 날짜에서 계산한 참고 표시다(같은 요일 4번 이상 결석). 점선 칩으로 구분하고 상담 필요 판정에는 영향을 주지 않는다.
- 관리 중 학생의 사유는 관리를 시작할 때의 신호라 "관리 사유 ○○"로 쓴다.
- 서버가 예정 없는 날의 제출 상태를 `MISSING`으로 보내는 경우 미제출로 세지 않는다. 실제 제출(`SUBMITTED`)과 0분보다 큰 학습 기록은 예정·입실 여부와 관계없이 보존한다.

## 정리한 시안

명부 표현은 세 가지(행 + 띠 + 막대, 기존과 같은 숫자 열 + 사유 칩, 사유별 묶음)를 같은 화면에서 비교했다. 1차 기능 심사(`reviews/10-function-result.md` 4장)가 행 + 띠 + 막대 안을 기본안으로 추천했고 나머지 두 안은 코드에서 정리했다.
