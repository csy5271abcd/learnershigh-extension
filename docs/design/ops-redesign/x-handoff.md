# 학생 케어 X 재구성 — 새 대화 인수인계 (2026-11-12)

새 대화는 이 문서부터 읽는다. **답은 한글로만 한다(영어 단어 섞지 않기).** 사용자 피드백이 더 오면 7장에 이어 적는다.

## 1. 결정

- **X를 메인으로 간다. Y·Z′는 폐기 방향**(코드는 지우지 않고 손대지 않는다. 지울지는 사용자 확인 후).
- **러너스하이 관리 화면 모양에 맞추는 것이 1순위.** 원래 화면 캡처(`references/existing-runners-high/screens/`)부터 비교하고 시작한다. 원래 화면이 경계가 흐리고 글자가 배경에 묻히는 모양이라면 그대로 둔다. 다만 사용자는 경계가 명확한 디자인을 선호한다.
- **학생 상세는 겹창(팝업)으로.** 학생 목록은 Z′처럼 한 줄에 한 명(이름 · 서버 관리 사유 · 그 값). 줄을 누르면 겹창. **같은 겹창 틀을 학습관별 화면에서도 쓴다**(학습관별에서 학생을 누르면 같은 겹창).
- **겹창 안 탭은 셋.**
  1. 출결·공부 시간·계획 진행률·입실 시각을 한 탭에(이름 후보: 학습 생활 / 출결·학습 / 학습관 생활 / 생활 기록 — 사용자에게 고르게 한다). 서버 관리 사유가 걸린 지표는 제목 색을 다르게(사용자 찬성).
  2. 사진 관찰(별도 탭).
  3. 상담(별도 탭): 지난 상담 기록을 보고, 지금 상담을 남긴다. 전체 상담 기록 보기도 필요(학생별 보기 가능). 기존 상담 컴포넌트·API만 쓴다(`components/AllHistory.tsx`, `notation/CareCounsel.tsx`). 새 저장소 만들지 않기.
- **비몰입 표시 기준**: 평균은 보여 주지 않는다. **공부 시간 비례 '시간당 3건 이상'이면 걸리게**(사용자: "1시간에 5번 이상이거나 … 시간 비례해서 시간당 3번 이상이 나을 것 같다"). 서버 판정이 아니라 화면 표시 기준이라 관리 기준 설정에서 바꿀 수 있게. 참고: 사진은 20초마다, 비몰입 한 건은 서버가 3분(자리 비움 5분) 이어진 행동을 확정한 것.
- **기준일을 오늘로**: 지금은 데모 자료가 9/23–10/27이고 API를 날짜 고정으로 띄워 기준일이 10/27이다. **오늘 기준 35일로 다시 생성**한다(6장).

## 2. 마우스 올림·상호작용

- 지금 값 상자(말풍선)가 대상과 떨어진 곳에 뜨거나 그림을 가리고, 모양이 억지스럽다. 올리면 경계선이 사라지고, 누르면 무엇이 나오는지 불명확하다.
- 원래 관리 화면처럼 줄·막대의 바탕만 살짝 바꾸고, 값은 대상 바로 옆에. 누를 수 있는 것은 누르면 무엇이 나오는지 보이게.

## 3. 그림 고칠 방향(사용자가 붙여 준 디자인 의견 참고)

사용자가 붙인 의견의 요지(그대로 따를 것이 아니라 참고):
- 문제는 색이 아니라 **자료를 그리는 방식**. 계획(회색 가로선)과 실제(막대)가 떨어져 있어 비교가 안 된다.
- **날짜별 계획과 실제**: 한 막대 안에 계획(뒤 회색 막대)과 실제(앞 색 막대)를 겹쳐 같은 자리에서 비교. 핵심 수치(이번 주 공부 시간 / 계획 시간, 달성률)를 그림 위에 크게.
- **과목별**: 세로 막대 대신 **가로 진행 막대**(과목 이름 · 시간 · 계획 대비 채운 비율). 축·격자 없이 단정하게. 지금은 축이 8시간까지라 막대가 바닥에 붙고 공간이 빈다.
- 단위 없는 숫자(0.7, 0.6) 금지, 그림 오른쪽에 뜬 '계획' 글자 금지, 날짜·요일 글자가 너무 작음.
- 위계: 제목 · 주요 수치 · 보조 정보의 크기·굵기 차이를 분명히. 가장 중요한 총 공부 시간과 달성률이 보여야 한다.
- 카드: 배경과 구분되는 얇은 테두리, 여백 20–24px로 통일, 글자 회색은 3단계 정도.
- 상단 요약 수치 카드(오늘 공부 시간 / 이번 주 누적 / 달성률 등) 제안도 있었다.

**예전 규칙과 부딪히는 점(새 대화에서 사용자에게 확인)**:
- 예전 피드백의 '막대 겹치기 금지'(S05)와 '계획을 뒤 막대, 실제를 앞 막대로 겹쳐 그리기' 제안이 부딪힌다. 이번 지시("참고해서 변경")가 최신이지만 그리기 전에 확인한다.
- '상자 안 글자·수치 금지'(S01)와 '상단 요약 수치 카드'가 부딪힌다. 확인한다.
- 의견의 색 값(#0F1117 등)·'Vercel Analytics + Linear 스타일'은 참고일 뿐, 1순위는 러너스하이 관리 화면 모양.

## 4. 학습관별 화면

- **한 행에 지표 하나.** 한 행에 둘을 둘 거면 의미 있게 짝지을 것(긍정/부정, 평균/벗어난 학생 등).
- **공부 시간**: 학습관 평균은 의미 없다. **학생별 공부 시간 변화량**(이 날·이 주에 평소 n시간이던 학생이 x시간으로 바뀐 것의 총량·분포, 줄어든/늘어난 학생 수)을 보여 준다.
- **계획 달성률은 좋은 지표**(유지).
- 맨 위 요약 줄('전체 160명 · 계획 미제출 34명 …')은 무엇을 말하는지 모르겠다는 지적 → 다시 구성.
- 학생을 누르면 학생 상세와 같은 겹창.

### 2026-11-12 사용자 답

- **첫 탭 이름: 학습관 생활.**
- **계획과 실제**: 계획은 점선(테두리만 있는 점선 상자나 꺾은선·선)으로 앞에, 실제는 막대로. 계획보다 더 많이 공부할 수 있으므로 실제 막대가 계획 점선을 넘어 보여야 한다. 시간 숫자는 잘 보이게. 테두리 없고 반투명한 바탕과 합쳤을 때 잘 보이는지 직접 확인한다.
- **핵심 숫자**: 숫자 네모 칸은 두지 않는다. 그림 제목 줄 옆에 크게(예: '12시간 30분 / 계획 18시간 · 달성률 69%').
- **X를 고치지 말고 X′로 새로 만든다.** `/student-care/x2`, 코드 `variants/x2/`. X는 그대로 둔다.
- **구분은 '확인 필요' 하나로**(점검일이 된 학생·확인할 학생을 묶음). 왜 걸렸는지·어디를 볼지는 겹창 맨 위(출결 표 위) '!' 안내 띠에.
- **그림 지적**: 두 칸에 우겨넣은 배치와 점선 상자·글자 겹침이 "더 최악". 좁은 곳에 우겨넣지 말고 흔히 쓰는 막대그래프 꼴로. → 그림은 한 줄에 하나, 뒤 옅은 회색 넓은 막대(계획·평소) + 앞 파란 좁은 막대(실제), 값 글자는 막대마다 실제 하나·기준 하나, 막대 색은 하나(기준에 걸린 칸은 값 글자만 빨강).

- **안내 띠가 애매하다**(여러 줄·글자·링크가 섞임) → 한 줄로: '! 확인 필요' + 사유마다 누를 수 있는 칸('공부 시간 감소 3시간 51분 · 평소 18시간 29분 ›'). 값은 같은 꼴의 짧은 한 마디로, 누르면 그 그림으로 간다.

- **지표 그림을 숨기지 않는다**: 35일 내내 결석인 학생에게 그림 대신 한 줄 안내를 띄웠더니 "다른 지표가 왜 사라졌냐". 값이 비어도 그림은 그대로 둔다(최근 7일 결석이면 주별로 바꾸는 것까지만).

- **참고 그림('주간 학습 현황') 꼴이 낫다** → 공부 시간·계획과 실제를 그 꼴로(`x2/x2Target.tsx`): 위 큰 숫자 '9시간 51분 / 계획 10시간 58분'과 오른쪽 달성률·표지, 진행 막대 / 실제 = 둥근 막대, 계획·평소 = 앞에 그린 점선과 흰 점, 옅은 점선 격자 / 그림 밑 가운데 범례 / 요약 줄 넷(하루 평균, 하루 평균 계획, 가장 많이 한 날, 계획을 채운 날). 막대 위 값 글자는 마우스를 올리거나 칸에 들어갈 때만 그 막대 위에. 요약 줄은 예전 '상자 안 수치 금지'와 부딪히지만 사용자가 보여 준 꼴이라 따랐다.
