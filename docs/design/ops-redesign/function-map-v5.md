# 기능 보존표 — 시안 A–D (5판)

`plan.md` 2장 유지 목록의 기능마다 네 안의 위치와 접근 경로, 검증 방법을 적는다. "검증"은 구현 후 채운다(측정·과업 문항·Codex 채점 증거 파일). 비교 방식을 바꾼 기능은 삭제가 아니라 대체로 적고 `contract-v5.md`에 근거를 둔다.

공통: 경로 `/student-care/{a,b,c,d}`, 상단에 지점 선택·기준일·관리 기준 설정(기존 `SettingsDialog`). 상담 기록·재확인·관리 이력은 기존 `CounselForm`·`RecheckPanel`·`AllHistory`를 그대로 쓴다.
