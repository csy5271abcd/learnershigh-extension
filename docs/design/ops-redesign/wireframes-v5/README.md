# 시안 A–D 배치도 (plan-v5 1.5단계)

`scripts/research/v5-wireframes.mjs`로 그린 정적 그림이다. 구조 확인용이며 숫자·이름은 자리 표시다(실제 값은 구현 때 API에서 온다). 폭 1600·1280, 높이 900. 결과·명단 상태는 `-full.png`(1600)에 문서 전체 길이를 함께 남겼다.

| 안 | 상태 | 파일 | 확인할 점 |
|---|---|---|---|
| A | 학생 기본 | `A-students-*` | 원본 표 유지, 상태·사유 글자, 사유 필터. 행에 날짜 그림 없음 |
| A | 학생 펼침 | `A-student-open-*` | 펼친 상세가 본문 전체 폭, 7일 값 가로 스크롤 없음, 비전 행·7일 비전 칸 |
| A | 학습관 기본 | `A-branch-*` | 지표 카드 4개 + 비전 카드가 첫 화면에(1600은 3열, 1280은 2열), 위에 "지표로 가기"·집계 제외 |
| A | 학습관 결과 | `A-branch-result-*` | 날짜를 누른 카드 행 바로 아래 전체 폭 결과(150행), "접기", 위 고정 "지표로 가기"로 다른 지표 이동(학생 목록을 지나지 않음) |
| B | 학생 기본 | `B-students-*` | 글자만 있는 명단(띠·막대·범례 없음) |
| B | 학생 팝업 | `B-student-modal-*` | 화면 대부분을 쓰는 모달(최대 1200px), 뒤 문서 잠금, 이전·다음 학생 |
| B | 학습관 기본 | `B-branch-*` | 사유별 학생 수(누르면 학생별 필터) + 지표 5줄이 같은 날짜 열로 정렬, 범위 띠에 직접 글자 |
| B | 날짜 팝업 | `B-branch-date-*` | 날짜를 누르면 팝업에 그 날짜·지표 학생 전원과 비교. 학습관 탭 본문은 밀리지 않음 |
| C | 확인할 학생 | `C-queue-*` | 한 학생 한 줄, 사유 전부 + 근거 문장, 사유 필터(학생 수), 서버 관리 상태·다음 확인 |
| C | 학생 서랍 | `C-drawer-*` | 오른쪽 서랍 1600에서 1200px, 1280에서 960px(75%), 배경 잠금, 지표 + 상담 기록 |
| C | 학습관 현황 | `C-branch-*` | 지표마다 한 줄: 날짜 변화 + 학생별 변화 분포(구간 인원 숫자). 5줄이 첫 화면에 |
| C | 학습관 결과 | `C-branch-result-*` | 결과가 그 지표 줄 바로 아래, 위 고정 "지표로 가기" |
| D | 학습관 | `D-branch-*` | 요약 5칸(값·날짜 직접 표기) + 선택 지표 상세(날짜 그래프 + 분포), 위에 이름 검색·"전체 학생 150명" |
| D | 학습관 결과 | `D-branch-result-*` | 요약 칸은 항상 위, 결과 학생은 선택 지표 상세 안 |
| D | 학생 화면 | `D-student-*` | 학생 전용 화면, "학습관으로"가 지표·날짜·검색·제외 복원 |

## 구조 축(P7)

| 축 | A | B | C | D |
|---|---|---|---|---|
| 첫 화면 단위 | 전체 학생 표 | 전체 학생 명단(글자) | 확인 대상 학생(사유·근거) | 학습관 요약 |
| 학생 선택 후 | 표 행 아래 펼침 | 모달 | 오른쪽 서랍 | 학생 화면 전환 |
| 학습관 지표 표현 | 지표 카드 격자 | 같은 날짜 열의 지표 줄(시간 우선) | 지표 줄 = 날짜 변화 + 학생 분포(분포 우선) | 요약 칸 + 선택 지표 상세 |
| 학습관 결과가 열리는 곳 | 카드 행 아래(같은 화면) | 날짜 팝업 | 지표 줄 아래(같은 화면) | 선택 지표 상세 안 |

A와 C는 결과가 같은 화면에서 열리지만 첫 화면 단위·학생 선택 후 동작·학습관 표현이 다르다. B와 C는 학생을 겹친 창으로 보지만 첫 화면 단위(전원 명단 / 확인 대상)·학습관 표현(시간 / 분포)·결과 위치(팝업 / 같은 화면)가 다르다.

## 23차 배치 관문 지적 반영

| 지적 | 수정 | 그림 |
|---|---|---|
| L01 B 날짜 팝업 탈출 | 팝업 머리글(제목·닫기·다른 지표·이전/다음 날짜·요약 값)을 팝업 안 고정 영역으로. 학생 150행은 그 아래에서만 움직임. 대화상자에 `role=dialog aria-modal=true` 표시 | `B-branch-date-{1600,1280}{,-mid,-end}.png` |
| L02 C 150행 | 첫 지표(결석) 아래에 7일 전체 학생 150행을 연 상태. 위 고정 "지표 전환 막대"(5지표, 각 10/26 값)와 결과 머리글 고정 "접기" | `C-branch-result-{1600,1280}{,-mid,-end}.png`, `-1600-full.png` |
| L03 D 요약 가독성 | 요약 5칸을 날짜 7칸 × 값 1줄 표로 바꿈(값·단위 직접 표기, 겹침 없음). 칸 폭 최소 420px 자동 배치(1600 3열, 1280 2열) — 가로 넘침 없음 | `D-branch-{1600,1280}.png` |
| L04 D 요약 접근 | 결과를 열면 요약 아래에 "지표 전환 막대"(5지표, 선택 날짜 값)가 위에 고정되고 결과 머리글의 "접기"도 고정. 결과 중간·끝에서도 보임 | `D-branch-result-{1600,1280}{,-mid,-end}.png` |

학생 행의 열 머리글과 자리 표시 값이 맞지 않는 곳은 구조 그림의 한계이며 구현에서 실제 값으로 바뀐다(23차 구현 주의 1).
