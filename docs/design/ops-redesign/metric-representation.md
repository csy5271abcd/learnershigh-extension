## 2. 지표별 결정

### 2.1 결석 (출결)

**성질.** 날짜별 범주다. 입실, 결석, 예정 없음, 미확인 네 상태가 있다. 결석은 예정이 있고 출결이 확인된 날에만 성립한다. 강남 150명의 7일(1,050 학생·일) 중 예정 없음이 150일, 미확인이 39일이다.

**답하는 질문.** S1, B2, B5. 횟수는 신호 판정 기준(`absenceDays`)과 정렬에 쓰인다. 하지만 운영자가 다음 행동을 고를 때 필요한 것은 날짜다. 연속 결석이 마지막 날까지 이어지는 중인지, 이미 끝나고 다시 나오는지, 특정 요일에 반복되는지에 따라 연락할 내용이 달라진다. "4일"이라는 숫자는 이 셋을 구분하지 못한다.

**지금 표현과 문제.** 학생별 목록은 "입실 2일" 숫자뿐이라 날짜와 연속 여부가 사라진다. 사유 칸은 "상담 필요 · 신규"만 보여주고 신호 문구는 "최근 7일 중 4일 미입실"이라 연속인지 알 수 없다. 상세의 7일 출결 표는 날짜를 보존하므로 적절하다. 다만 7일로는 같은 요일 반복을 볼 수 없다. 7일 안에 같은 요일은 한 번뿐이기 때문이다. 학습관별 결석 카드는 날짜마다 "68 미입실"처럼 예정 없음과 결석을 한 숫자에 섞는다(`plan.md` 3장).

**후보.**

| 후보 | 장점 | 단점 | 판정 |
|---|---|---|---|
| 횟수 숫자/막대 | 정렬이 쉽다 | 날짜·연속·요일이 사라진다. 0/1 사건을 길이로 그린다(F10) | 기각 |
| 7칸 상태 띠 (행마다) | 날짜가 남고, 칸 수로 횟수도 셀 수 있고, 연속은 붙은 칸으로 보인다 | 같은 요일 반복은 안 보인다 | **목록에 채택** |
| 연속 구간을 하나의 막대로 합친 타임라인 | 구간 길이가 잘 보인다 | 날짜 경계가 사라지고 칸 수를 셀 수 없다 | 기각 |
| 35일 달력 (행 = 주, 열 = 요일) | 연속은 가로로, 같은 요일 반복은 세로로 보인다. 정기 휴무(예정 없음)가 세로 공백으로 드러나 결석과 구분된다 | 7칸보다 크다. 150명에 반복하면 과하다 | **상세에 채택** |
| 원/파이 | 없음 | 날짜 정보가 없다 | 기각 |

**선택과 이유.** 목록 행에는 7칸 상태 띠를, 학생 상세에는 35일 달력을 둔다. 띠는 Grafana status history처럼 같은 상태가 이어져도 칸을 합치지 않는다. 칸을 합치면 날짜 경계와 횟수가 사라진다. 달력은 정부 분석 지침(Analysis Function)이 시계열에 권하는 달력형 열지도 형식을 따른다. 기존 상세 7일 출결 표는 유지하되 달력 위쪽 행으로 흡수한다.

**칸 규칙.** 입실은 옅은 중립색으로 채운다. 결석은 진한 경고색으로 채우고 칸 안에 × 모양을 넣는다. 예정 없음은 채우지 않고 칸 자리에 짧은 가로줄만 둔다. 미확인은 점선 테두리만 그린다. 네 상태가 채움·모양·테두리로 달라서 색을 못 봐도 구분된다. 칸은 12px, 칸 사이는 2px다.

**사유 문구.** FE가 `review.days`에서 결석 구간을 계산해 고른다. 예정 없음은 구간을 끊지도 세지도 않고 건너뛴다. 미확인은 구간을 끊는다. 표시용 계산이며 백엔드 판정 공식은 바꾸지 않는다.

| 날짜 모양 | 사유 문구 |
|---|---|
| 2일 이상 연속, 마지막 날(10/27)까지 이어짐 | `결석 4일째` |
| 2일 이상 연속, 끝남 | `결석 3일 연속` |
| 흩어짐 | `결석 3일` |
| 35일 중 같은 요일 3회 이상 (추가 표시) | `매주 수 결석` |

**150명 확장.** 띠는 98px 폭에 7일을 담는다. 날짜와 요일 머리글은 목록 상단에 한 번만 두고 고정한다. B5(그날 누가 결석했나)는 머리글 날짜를 누르면 그날 결석한 학생 행만 남기는 필터로 답한다. 학습관별 탭의 날짜별 결석 명단 펼침(G29)은 유지한다.

### 2.2 계획 제출

**성질.** 날짜별 범주(제출/미제출/미확인)다. 예정 없는 날은 API가 `MISSING`으로 주지만 신호 계산은 이 날을 빼므로(`planMissingDays`, `scheduled != false`) 화면에서도 대상 아님으로 그린다. 제출 여부는 학습량이나 계획의 질을 뜻하지 않는다.

**답하는 질문.** S1, B1. 미제출이 결석일과 겹치는지가 핵심이다. 강남 12명은 미제출 날짜가 결석 날짜와 같다.

**지금 표현과 문제.** 목록은 "2 / 6일" 숫자라 날짜가 없고, 결석과 겹치는지도 알 수 없다. 상세 7일 표의 제출 행은 적절하다.

**후보.** 숫자 "n / m일"은 기각한다. 날짜가 없다. 결석 띠와 같은 칸에 표식을 겹치는 안은 한 칸에 두 범주를 섞어 읽기 규칙이 늘어나므로 기각한다. **결석 띠 바로 아래에 같은 날짜 열로 두 번째 띠를 두는 안을 채택한다.** 두 띠의 열이 맞아서 미제출과 결석이 같은 날인지 위아래로 바로 보인다.

**칸 규칙.** 제출은 옅게 채운다. 미제출은 진하게 채운다. 결석 경고색과 다른 색을 쓴다. 대상 아님은 비우고, 미확인은 점선 테두리다.

**사유 문구.** 미제출 날짜가 모두 결석일이면 사유는 따로 세우지 않고 결석 사유 뒤에 `· 같은 날 계획 미제출`을 붙인다. 신호는 그대로 남고 문구만 합친다. 입실한 날의 미제출이 있으면 `계획 미제출 3일(입실일 2)`처럼 쓴다. 상세는 35일 달력을 출결 달력 옆에 같은 크기로 둔다(작은 다중 차트).

### 2.3 학습 시간

**성질.** 0이 의미 있는 분 단위 양이다. 학생마다 평소가 3시간부터 10시간까지 다르다(반례 1). 비교 기준은 두 가지다. 신호는 이전 28일 합÷4인 주평균과 7일 합계를 비교하고(`studyDrop`), 상세는 같은 요일 평소와 날짜별로 비교한다. 두 기준의 표본이 다르다는 점은 기존 조사 5장에 있다. 결석일은 0분으로, 미확인일은 null로 온다.

**답하는 질문.** S2, B1, B4. 비율과 절대량이 함께 필요하다(반례 6).

**지금 표현과 문제.** 목록은 "6시간 18분 / 19시간 53분" 두 줄 텍스트다. 150행이면 숫자 300개를 읽어야 하고 감소폭은 머릿속으로 빼야 한다. 상세는 꺾은선이다. 날마다 독립된 양을 선으로 이어 연속량처럼 보이게 하고, 결석일에 0분 점을 찍어 결석과 실제 0분을 같은 점으로 만든다. 학습관별 카드는 개인 % 변화의 분포와 학생 선을 겹쳐 그려서 선이 엉킨다.

| 목록 스파크라인 (7일 분 꺾은선) | 기각. 평소 기준이 없으면 감소인지 알 수 없고, 축이 행마다 다르면 3시간형의 작은 흔들림이 크게 보인다 |

| 상세 꺾은선 (지금) | 기각. 결석 0과 실제 0이 섞인다 |
| 상세 날짜별 막대 + 같은 요일 평소 눈금 | **채택** |

**선택과 이유.** 목록 불릿은 Few의 불릿 그래프 구조에서 주 측정값과 비교 측정값만 쓴다. 좋음·나쁨 구간 띠는 쓰지 않는다. 검증된 개인 정상 범위가 없기 때문이다(반례 13, 기존 조사 B). 모든 행이 같은 축에서 0부터 시작하므로 막대 끝과 눈금 사이 거리가 곧 줄어든 시간이다. 공통 축 위 위치 비교가 가장 정확하다는 Cleveland & McGill의 결과를 따른다. 3시간형과 10시간형은 막대 길이가 다르지만 눈금이 막대 끝에 붙어 있어 정상으로 읽힌다(반례 1). 같은 −50%라도 5분 감소와 300분 감소는 막대 거리 차이로 다르게 보인다(반례 6). 7일 합계는 막대 오른쪽에 `17시간`처럼 정수 시간으로 적는다. 주평균은 눈금으로만 보이고, 정확값은 행 hover/focus와 상세에서 읽는다.

상세 막대는 0에서 시작하고(분석 지침의 막대 축 절단 금지), 같은 요일 평소는 막대마다 짧은 가로 눈금으로 그린다. 결석일에는 막대를 그리지 않는다. 그 열은 바로 위 출결 띠에 결석 칸이 있으므로 따로 글자를 쓰지 않는다. 입실했는데 0분인 날은 기준선 위에 높이 2px짜리 막대를 그려 결석일의 빈칸과 구분한다. 미확인일은 빈칸이고 출결 띠가 미확인을 보여준다. 평소 표본이 0인 날(그 요일이 늘 예정 없음)은 눈금을 생략한다.

**사유 문구.** `학습 −8시간(−42%)`. 백엔드 문구 "최근 7일 7시간 50분 · 평소 18시간"보다 짧고 절대량과 비율을 둘 다 담는다.

**150명 확장.** 불릿은 140px 폭에 축 눈금(0·20·40·60시간)을 목록 머리글에 한 번만 둔다. 학습관 전체 변화(B4)는 학습관별 탭의 날짜별 "개인 % 변화의 중앙값과 중간 50%, 0% 기준선" 그림을 유지한다(기존 조사 A·B). 학생 선 겹쳐 그리기는 뺀다. 변화 학생은 학생별 목록의 사유로 이미 이름이 나오기 때문이다.

### 2.4 입실 시각

**성질.** 하루 중 시각이다. 크기 비교가 아니라 위치 비교이고, 결석·예정 없음인 날은 값이 없다. 강남 실측 범위는 8:08–21:03이다. 비교는 본인 같은 요일 평소와의 분 차이이고 신호 기준은 평균 +60분(`startShiftMinutes`)이다. 같은 요일 평소의 표본은 최대 4개다(`startSamples`).

**답하는 질문.** S3, B4. 늦은 날이 며칠인지, 하루만 크게 늦었는지, 계속 조금씩 늦는지(기존 조사: +100분 한 번과 +30분 여러 번은 다른 패턴).

**지금 표현과 문제.** 상세는 입실한 날끼리 선으로 잇는다. 결석으로 끊긴 날 사이의 선은 없지만, 하루 건너 입실한 날도 이어지는 구간이 있어 연속 관측처럼 보인다. 학습관별 입실 카드는 개인 편차 분포에 학생 선이 겹친다(baseline 화면). 목록에는 입실 시각이 없다.

**후보.**

| 후보 | 판정 |
|---|---|
| 꺾은선 (지금) | 기각. 빈날 양쪽을 잇는 것은 분석 지침이 금지한다 |
| 날짜별 점 + 같은 요일 평소 눈금 + 둘 사이 세로 연결선 (덤벨) | **채택** |
| 평소 대비 편차(분) 막대 | 보류. 실제 시각이 사라져 "몇 시에 왔나"를 다시 물어야 한다 |
| 목록 행에 7일 미니 차트 | 기각. 신호 학생이 강남 5명뿐인데 150행에 차트를 더하면 텍스트·높이 목표를 넘는다 |

**선택과 이유.** 상세의 세로축은 시각이고 위가 이른 시각이다. 그 학생 값에 맞춰 정시 단위로 범위를 잡는다. 점은 실제 첫 입실, 짧은 눈금은 같은 요일 평소, 둘을 잇는 선의 길이가 늦은 분이다. 날짜끼리는 선을 잇지 않는다. 데이터 없는 구간을 잇지 말고 점을 보여주라는 분석 지침과 Datawrapper의 결측 처리 원칙을 따른다. 결석·예정 없음 열은 점 없이 비워 두고, 상태는 같은 열의 출결 띠가 보여준다. 입실은 했는데 시각이 없는 날은 열 아래에 `시각 없음`을 쓴다. 60분 기준선이나 정상 범위 띠는 그리지 않는다. 사용자가 60분 요약을 지운 결정(G15)과 개인 변동 폭을 추정할 수 없다는 점(반례 13)이 이유다. 평소 표본이 4개 미만인 날은 눈금을 속이 빈 모양으로 그린다.

**사유 문구.** `입실 +98분(5일 평균)`. 몇 날을 평균했는지 괄호에 둔다.

**150명 확장.** 목록 행에서는 사유 칩으로만 보인다. 학습관 전체(B4)는 날짜별 개인 편차의 중앙값과 중간 50%, 0분 기준선을 유지한다. 평균은 쓰지 않는다. 늦은 학생과 이른 학생이 상쇄되기 때문이다(반례 5).

### 2.5 계획 대비 진행률

**성질.** 같은 날의 실제 분 ÷ 계획 분이며 100%를 넘을 수 있다. 강남 7일 입실일 819일 중 60일이 100%를 넘고, 42일은 계획이 없어 계산할 수 없다. 7일 진행률은 계획 분 합 대비 실제 분 합이다(`executionGap`, 입실·계획 양수·실제 기록이 있는 날만).

**답하는 질문.** S4, B1. 신호는 7일 진행률 60% 미만(`executionRatePercent`)이다.

**지금 표현과 문제.** 목록의 "91% / 비교 2일"은 적절한 단일 값이다. 다만 "비교 2일"은 무엇을 비교했는지 읽히지 않는다. 상세 꺾은선은 100% 기준선이 있고 계산 불가일을 `미제출`/`—`로 구분하므로 의미는 맞다. 하지만 날짜별 비율을 선으로 이어 추세처럼 보이게 한다.

**후보.**

| 후보 | 판정 |
|---|---|
| 목록 텍스트 `93%` | **유지**. 값 하나는 차트가 아니라 숫자로 충분하다(dataviz 형식 선택) |
| 학습 시간 막대에 계획 눈금을 하나 더 얹기 | 기각. 한 막대에 평소·계획 두 기준이 겹친다 |
| 상세 날짜별 점 + 100% 기준선, 축 상한은 최대값까지 | **채택** |
| 100%에서 자르는 게이지 | 기각. 초과를 숨긴다(G23) |

**선택과 이유.** 상세에 학습 시간 막대와 같은 날짜 열을 쓰는 별도 줄을 둔다. 축은 0%부터 `max(150%, 최댓값 올림)`까지이고 100%에 가는 기준선을 긋는다. 100% 초과 점에 좋음·나쁨 색을 칠하지 않는다. 계획이 없거나 0분인 날은 점 없이 열 아래에 `계획 없음`을 쓴다. 0%(계획은 있는데 실제 0분)는 0% 위치에 점을 찍어 계산 불가와 구분한다(반례 10). 7일 진행률은 줄 오른쪽에 `7일 86% · 계획 18시간 중 15시간`으로 적는다. 분 합을 같이 적는 이유는 비율만으로 계획 증가와 실제 감소를 구분할 수 없어서다(기존 조사).

**사유 문구.** `진행률 41%`.

**150명 확장.** 학습관 단위로 진행률을 요약해야 하면 학생 비율의 평균이 아니라 분 합÷분 합을 쓰고 이름을 `학습관 계획 분 대비`로 붙인다(반례 9). 이번 범위에서 학습관별 탭에 새로 넣지는 않는다.

### 2.6 과목별 비중

**성질.** 4과목(국어·수학·영어·탐구) 계획·실제 분의 구성비로 합이 100%다. 신호는 계획 비중 − 실제 비중이 가장 큰 과목의 차이가 20%p 이상일 때다(`subjectShareGapPoints`). 강남 최대 차이는 31%p, 중앙값은 0%p다. 계획을 낸 입실일만 합산한다.

**답하는 질문.** S5. 이 지표는 매일 볼 지표가 아니라 사유로 올라온 학생에게만 의미가 크다(강남 5명).

**지금 표현과 문제.** 상세는 과목마다 계획 막대와 실제 막대를 0–100% 공통 축에 위아래로 두고 %p 차이를 머리에 적는다(`SubjectAllocation`). 공통 기준선에서 비교하므로 적절하다. 지금 표현의 문제는 비중만 보여서 과목 시간이 그대로인데 비중만 내려간 경우(반례 11)를 구분할 수 없다는 것뿐이다.

**후보.**

| 후보 | 판정 |
|---|---|
| 계획·실제 원그래프 두 개 | 기각. 각도 비교는 부정확하고, 분석 지침은 원그래프를 의미 있는 전체·5개 이하·한 조각이 클 때로 한정한다 |
| 100% 누적 막대 두 줄 | 기각. 가운데 과목은 기준선이 달라 비교가 어렵다(Datawrapper 누적 막대) |
| 과목별 계획·실제 막대 쌍, 0–100% 공통 축 (지금) | **유지** |
| 과목별 %p 차이 발산 막대 | 보류. 차이만 남고 원래 비중이 사라진다 |

**선택과 이유.** 지금 표현을 유지한다. 바꾸지 않는 것도 근거 있는 결정이다. 공통 기준선 위 길이 비교(Cleveland & McGill), 원그래프 제한(분석 지침), 누적 막대 한계(Datawrapper)가 모두 지금 선택을 지지한다. 추가할 것은 하나다. 신호 과목 행 끝에 `실제 60분 / 계획 60분`처럼 분을 적어 비중 변화와 시간 변화를 구분한다. 나머지 과목의 분은 hover/focus에서 읽는다. 신호 과목만 강조색이고 나머지는 회색이다.

**사유 문구.** `수학 비중 40→18%`.

## 3. 지표를 함께 보는 배치

### 3.1 150명을 한 번에: 정렬된 표 + 행 안의 작은 그림

후보는 세 가지였다. 첫째, 학생 × 날짜 큰 행렬에 모든 지표를 색으로 칠하는 안은 범주와 양을 한 칸 색에 섞게 된다. 지표 6개 중 4개가 양이라 열지도의 색 농도로는 정확한 비교가 안 된다(Cleveland & McGill의 순위에서 채도는 낮다). 둘째, 학생마다 작은 차트를 반복하는 small multiples는 150개 패널이 되어 기존 조사 D의 결론대로 스크롤 비용이 크다. 셋째, **한 행 = 한 학생인 표에 단어 크기 그림(상태 띠, 불릿)을 넣는 안**을 채택한다. Tufte가 스파크라인을 표 안에 쌓아 행끼리 비교하게 한 방식이고, NN/g 데이터 표 글의 네 과업(찾기·비교·한 행 보기·조치)과도 맞는다.

| 열 | 내용 | 폭(1600px) | 텍스트 |
|---|---|---:|---|
| 학생 | 이름, 반 약칭(`3A`) | 110px | 5자 |
| 사유 | 칩 0–2개, 칩당 1줄 | 가변 | 확인 대상만 |
| 7일 | 출결 띠 위, 제출 띠 아래. 날짜·요일 머리글 고정 | 98px | 0 |
| 학습 시간 | 불릿(0–60시간 공통 축) + `17시간` | 190px | 4자 |
| 진행률 | `93%` | 56px | 3자 |

행 높이는 26px다. 띠 두 줄(12+2+12px)이 들어가는 최소 높이다. 150행 × 26px = 3,900px에 상단 영역 약 350px를 더하면 4,250px로 900px 화면 4.7개다(목표 5화면 이하). 텍스트는 행당 약 12자 × 150 = 1,800자, 사유 칩 41명 × 평균 12자 + 2개째 칩 15개 ≈ 670자, 머리글·탭 약 250자로 합계 약 2,700자다(목표 2,800자 이하). 둘 다 추정치라 2단계 측정기로 확인한다. 2,800자를 넘으면 먼저 반 약칭을 검색·필터 조건으로 옮긴다. 입실 일수와 제출 일수는 숫자를 쓰지 않고 띠의 칸 수로 보인다. 이 결정은 기존 목록 열 두 개를 그림으로 바꾸는 것이라 `function-map.md`에 "값 → 칸 수"로 적고 과업 시험으로 확인한다.

정렬은 확인 대상 → 관리 중(재확인일 도래 먼저) → 정상(이름순)이다. 확인 대상 안에서는 결석 → 학습 감소 → 진행률 → 입실 → 과목 → 미제출만 있는 학생 순으로 둔다. 이 순서는 판정이 아니라 제안이며 과업 시험은 순서가 아니라 포함 여부로 채점한다(`plan.md` 5장). 정상 학생 행은 사유 칸이 비고 회색 계열이다. 강조색은 확인 대상의 칩과 결석·미제출 칸에만 쓴다. 대부분이 정상일 때 예외만 눈에 띄게 하라는 NN/g 대시보드 글의 색 사용 원칙을 따른다.

필터는 목록 위 한 줄에 둔다. 검색, 사유 종류(칩과 같은 이름), 날짜 머리글 클릭(그날 결석) 세 가지다. 펼침·접기·포함·제외 조작은 행에 두지 않는다. 행 150개의 펼침 버튼이 사라지므로 상태 전환 조작 목표(20개 이하)에 닿는다.

**기존 계약과의 충돌.** F03·G03은 "전원 명부에 날짜별 그래프·세부기록을 떡칠하지 않는다"이다. 7칸 띠와 불릿은 축·범례·선이 있는 차트가 아니다. 지금 행에 있던 숫자 텍스트("2 / 6일", "6시간 18분 / 19시간 53분")를 같은 정보량의 단어 크기 그림으로 바꾸는 것이다. 그래도 날짜별 표시가 명부에 들어가므로 `contract-changes.md`에 F03·G03 변경으로 기록하고 텍스트 감소량을 근거로 남긴다. 2단계 최소 변경안은 띠 없이 기존 숫자 열을 유지해 비교 대상이 된다.

### 3.2 한 학생을 한 화면에: 날짜 열을 공유하는 세로 묶음

목록 행을 누르면 오른쪽에 모달이 아닌 상세 패널이 열리고 목록은 그대로 보인다. NN/g 데이터 표 글은 행 안 펼침(아코디언)이 열린 채로 남아 목록을 어지럽히고 먼 행을 참조하기 어렵다고 지적하며 비모달 옆 패널을 대안으로 든다. 지금 화면의 행 안 펼침이 목록을 밀어내는 문제(원본 캡처)와 같다. 단계는 목록과 상세 두 단계로 끝낸다. 지표마다 "상세" 버튼을 두지 않는다(F04, NN/g 점진적 공개 2단계).

| 블록 | 내용 | 높이(약) |
|---|---|---:|
| 머리 | 이름·반·상태, 사유 칩(목록과 같은 문구) | 64px |
| 7일 묶음 | 열 7개(날짜·요일)를 공유한다. 출결 띠 → 제출 띠 → 학습 분 막대+평소 눈금 → 입실 시각 점+평소 눈금 → 진행률 점+100% 선. 왼쪽 열에 이름·단위·축 값 | 330px |
| 7일 숫자 | `7일 15시간 · 주평균 18시간 · 입실 5일 · 제출 4/6일 · 진행률 86%`. 기존 목록 값을 한 줄로 보존 | 24px |
| 35일 달력 | 출결·제출 달력 두 개를 나란히(주 6줄 × 요일 7열, 칸 14px) | 110px |
| 과목 비중 | 4과목 막대 쌍(유지), 신호 과목 분 표기 | 170px |

합계 약 700px라 1600×900에서 머리 아래 한 화면에 들어간다. 상담 기록은 그 아래에 이어진다. 날짜 열을 공유하므로 "결석한 날 → 그날 막대 없음 → 그날 입실 점 없음"이 세로 한 줄로 읽힌다. 분석 지침의 small multiples 원칙(같은 축 공유)을 날짜축에 적용한 것이다. 세로축은 지표마다 다르다. 분, 시각, %를 한 축에 섞지 않기 위해서다(dataviz 단일 축 원칙). 850px 폭에서는 패널이 목록 위를 덮는 전체 폭 패널이 되고, 390px에서는 7일 묶음의 열 폭이 40px로 줄어든다. 날짜는 일(日)만, 요일은 한 글자로 쓴다.

### 3.3 "왜 올라왔나"를 한 줄로

사유는 칩 하나에 지표 이름 + 핵심 수치 하나 + 필요하면 괄호 하나로 쓴다. 문장으로 쓰지 않는다. 날짜는 칩에 쓰지 않는다. 바로 옆 띠가 날짜를 보여주기 때문이다. 스냅숏에서 한 학생의 신호는 최대 2개(강남 41명 중 15명)라 칩 두 개로 접힘 없이 모두 보인다. 3개 이상인 학생이 생기면 줄을 바꾸고 "+n"으로 숨기지 않는다(필수 사유를 숨김 영역에만 두는 것은 필수 불통과 조건).

| 신호 | 칩 | 백엔드 문구 (비교) |
|---|---|---|
| CONSECUTIVE_ABSENCE | `결석 4일째` / `결석 3일 연속` / `결석 3일` (+ `· 같은 날 계획 미제출`) | 최근 7일 중 4일 미입실 |
| PLAN_MISSING | `계획 미제출 3일(입실일 2)` | 최근 7일 중 4일 미제출 |
| STUDY_DROP | `학습 −8시간(−42%)` | 최근 7일 7시간 50분 · 평소 18시간 |
| EXECUTION_GAP | `진행률 41%` | 최근 7일 계획 달성률 41% |
| START_TIME_SHIFT | `입실 +98분(5일 평균)` | 평소보다 98분 늦게 입실 |
| SUBJECT_SHARE | `수학 비중 40→18%` | 수학 계획 40% → 실제 18% |

칩 수치는 백엔드 `signals`의 값으로 만들고, 결석 연속 여부와 같은 날 미제출 여부만 `review.days`에서 계산한다. 백엔드가 "달성률", 화면이 "진행률"로 다르게 부르는 문제는 화면 용어인 "진행률"로 통일한다.

### 3.4 학습관별 탭

지표 4개를 각자 카드·범례·요약·학생 표로 반복하던 구성을 날짜 열 7개를 공유하는 한 묶음으로 바꾼다. 학습 시간 줄은 개인 % 변화의 중앙값·중간 50%·0% 선이다. 입실 줄은 개인 분 편차의 중앙값·중간 50%·0분 선이다. 결석 줄은 날짜별 결석 학생 수이며 분모는 `예정·확인 n명`이고, 미확인 수를 따로 적는다. 제출 줄은 날짜별 미제출 수이며 분모는 예정일 학생 수다. 학생 선과 학생 표는 빼고, 각 줄의 "변화 학생"은 학생별 목록을 그 사유로 필터해 연다. 결석 날짜 클릭 → 같은 줄 안에 그날 명단 펼침(G29)과 학생 제외·복원(G17)은 유지한다. 집단 전체가 함께 변하면 중앙값이 0선에서 떨어진 것으로 드러난다(반례 4).

## 5. 반례 13개 연결

| 반례 | 선택한 표현에서 어떻게 보이는가 |
|---|---|
| 1 정상 3시간형/10시간형 공존 | 불릿 막대 길이는 다르지만 주평균 눈금이 막대 끝에 붙어 감소로 보이지 않는다. 사유 칩도 없다 |
| 2 10시간 → 6시간 (집단 평균 부근) | 공통 축 불릿에서 막대 끝과 눈금 사이 4시간 거리가 보인다. 칩 `학습 −4시간(−40%)` |
| 3 60명 중 3명 +100분 (평균 +5분) | 평균을 쓰지 않는다. 세 학생은 각자 칩 `입실 +100분`으로 목록에 오른다. 학습관 줄은 중앙값·중간 50%라 평균 희석을 대표값으로 보이지 않는다 |
| 4 전원 +100분 (IQR 밖 0명) | 판정은 개인 기준이라 전원이 칩을 받는다. 학습관별 입실 줄의 중앙값이 0분 선에서 +100분으로 떨어져 집단 변화로 보인다 |
| 5 +100분/−100분 상쇄 | 칩은 개인별이라 늦은 학생만 오른다. 학습관 줄은 평균이 아닌 중앙값·퍼짐이다 |
| 6 같은 −50%, 5분 vs 300분 | 칩에 시간과 %를 함께 쓴다. 불릿 거리가 5분과 300분으로 다르게 보인다 |
| 7 결석으로 예정일 평균만 감소 | 결석 신호가 있으면 백엔드가 학습 감소를 판정하지 않는다. 상세에서 입실일 막대는 평소 눈금에 닿고 결석일 열은 비어 원인이 결석임이 보인다 |
| 8 4일 감소 + 하루 500분 | 목록 불릿은 합계라 감소가 안 보일 수 있다(한계). 상세 날짜별 막대 4개가 평소 눈금 아래에 있어 반복 감소가 보인다. 목록에서 찾으려면 백엔드 신호가 필요하며, 이 표현만으로 목록에 올리지는 못한다 |
| 9 진행률 평균 125% vs 분 합 57% | 학생 비율 평균을 표시하지 않는다. 학습관 요약이 필요하면 분 합÷분 합으로 이름을 붙인다 |
| 10 계획 0분·실제 120분 | 상세 진행률 줄에 점 없이 `계획 없음`. 0% 점과 다르다 |
| 11 과목 시간 유지, 비중 60→30% | 신호 과목 행에 `실제 60분 / 계획 60분`을 적어 시간 감소가 아님을 보인다 |
| 12 예정 60·확인 20·결석 3 | 학습관별 결석 줄의 분모를 `예정·확인 20명`으로 쓰고 미확인 40명을 따로 적는다. 목록 띠는 미확인을 점선 칸으로 남겨 결석·입실로 바꾸지 않는다 |
| 13 평균 같고 변동 폭 다른 두 학생 | 정상 범위 띠를 그리지 않는다. 상세 입실 줄에 평소 눈금 하나만 두고 표본 4개 미만은 속 빈 눈금으로 표시한다. 개인 변동 폭 차이는 이 화면이 해결하지 못하는 한계로 남긴다 |

## 6. 남은 불확실성과 확인 방법

**결석 패턴 데이터 부족.** 스냅숏에는 흩어진 결석과 같은 요일 반복 결석이 없다. 2단계 와이어프레임에는 API 스냅숏 외에 반례용 고정 행 3개를 따로 둔다. 흩어진 결석 3일, 매주 수요일 결석, 마지막 날까지 이어지는 결석이다. `결석 3일`·`매주 수 결석`·`결석 4일째` 칩과 달력 세로줄이 보이는지 확인한다. 고정 행은 화면에 "예시"로 표시하고 과업 시험 채점에서는 뺀다.

**텍스트·높이 추정.** 2,700자와 4.7화면은 계산 추정이다. 2단계에서 `scripts/research/care-screen-metrics.mjs`로 3폭 × 2테마를 측정한다. 넘으면 3.1의 순서대로 줄인다.

**계약 변경.** 명부의 띠·불릿(F03·G03)과 입실·제출 일수 숫자의 그림 대체를 `contract-changes.md`에 적는다. 최소 변경안과 같은 과업으로 비교해 조작 수·정답률이 나빠지면 숫자 열로 되돌린다.

**학습 시간 기준 두 개.** 목록 불릿은 주평균(28일 합÷4), 상세 눈금은 같은 요일 평소다. 이름을 `주평균`과 `평소(같은 요일)`로 다르게 붙인다. 둘이 다른 답을 내는 학생이 있는지 2단계 데이터로 센다.

**반례 8의 목록 누락.** 목록 불릿은 합계라 하루 장시간이 반복 감소를 가린다. 이 학생을 목록에 올리려면 백엔드 판정 변경이 필요하고, 판정 공식은 이번 범위에서 바꾸지 않는다. 상세에서만 보인다는 한계를 `function-map.md`에 남긴다.
