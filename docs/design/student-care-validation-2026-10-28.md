# 10/28 검수 기록 — 로컬 범위 통과

## 최신 재검수 진행

아래의 이전 미해결 항목은 공식3 구현으로 수정했다. 입실 개인 요일 편차/정기휴일 제출 제외/과목 동일 날짜 비교 및 구버전 snapshot 보호, startSamples 보존을 적용했다. BE270개 단위·학생케어 MySQL75개·FE80개·seed6개와 타입/린트/빌드는 통과했다. independent code review가 추가 발견한 음수 편차 표시/비교불가 이력도 반례 RED→GREEN 확인 후 수정했다. 새 재확인 화면은 ‘90분 늦음/15분 빠름/평소와 같음’, 구버전 CLOCK 표시를 구분한다.

최신 냉독은 모바일 기호 설명 잘림이 없는 것과 관리 이력 긴 원문/학생 선택/현재 지표 버튼의 구별을 직접 확인했다. 실제 오른쪽 브라우저에서 오류 재시도·현재 명부6/6일 제출 분모·이하린 카드7일 상세·관리 이력 학생 선택을 직접 조작했다.

실행 중인 build/libs JAR를 다시 빌드하여 일부 lazy class loading이 실패한 검증 run은22통과/4실패로 종료됐으며 전체 통과로 처리하지 않았다. immutable `.local-runtime/care-api-formula3-final.jar`로 재시작한26개가 모두 통과했다. 같은 문제 재발 방지를 handoff/README에 남겼다.

로컬 care-demo 원본 학생의 개발용 상담1건을 기존 POST API로 추가했다. 원문에 `[화면 확인용 예시]`를 명시했으며 과거 저장 기록을 덮어쓰지 않았다. 상담101분/단위MINUTES/formula3,이벤트2개를 확인했다. 실제 DB→API content→화면 원문 정확 일치/학생별 조회의 추가 Playwright1개는 통과했다. 최초0건 상태와 fixture 긴 원문 검사는 아래 당시 기록으로 남긴다.

## 최신 구현과 실제 검증

- 최종5의 학습관은 개인 평소 대비 학습 변화율/입실 분 편차의 전체 분포+중간50%+평균+변화 학생 식별을 연결했다. 전체 관측을 반영하고 최대6명을 색으로 비교한다. IQR 밖이라는 이유만으로 상담 필요를 확정하지 않는다.
- 날짜/학생 클릭은 같은 카드에서7일 원문 기록을 펼친다. 이전 공통 맨 아래 이동은 제거했다. 결석은 기존 날짜별 표시를 유지한다.
- `— 일정 없음`, `? 비교 기록 부족`을 구별하고, 실제 제출/예정 밖 실제 입실을 보존했다. 입실 기여 표의 중복 수치를 평소/최근 시각과 차이로 분리했다.
- Node 모델/API77개 PASS(관리 이력 추가 전). Admin build/type/lint PASS. 기존 chunk 크기 경고는 남는다.
- Playwright 전체18개 PASS 후 범례·실제 제출·추가 입실·이름 선택·3폭×2테마6개 재검증 PASS, 기호/결측 구간/제외·복원·3폭×2테마4개 재검증 PASS. 결과는 서로 중복되므로 합산하여 고유 테스트 수로 주장하지 않는다.
- 독립 화면 독해: 전체60명/기간/개인 기준/중간50%/감소5명/지연3명 구분. 최초의 ‘이하린 결측일 보라선 연결’ 지적은 다른 선과의 겹침으로 재독해에서 철회됐다. 실제 최근 원본으로 결측 날짜 양옆 선이 생성되지 않는 Playwright 검사도 PASS.
- 냉독에서 모바일 입실 표 기호 설명 왼쪽 잘림을 지적했다. 최종 캡처/DOM 글자 영역을 재측정해야 하므로 G38/G53 최종 통과는 보류한다.
- 독립 코드 검토는 추가 입실, 제출 우선, 의미 구분, 근처 툴팁 등을 확인했다. BE와 화면 계산 의미 불일치를 별도 차단 사유로 남겼다.

## 관리 이력 추가 요구 G54

학생 선택(전체 명부와 이력 없는 학생 포함), 이름/반 검색, 이름 클릭으로 해당 학생 이력 필터, 각 행의 원문 펼치기 추가. 내용은 기존 API content를 그대로 사용한다. 긴 원문/줄바꿈은 보존하고 현재 지표는 별도 버튼으로 구분한다. 과거 작성자나 과거 지표를 추정하지 않는다.

모델3개 PASS, 타입/린트/빌드 PASS, Playwright 신규3개+기존 원본/비교/명부/상담4개=7개 PASS. 독립 코드 검토가 같은 지점 명부 갱신 때 제거된 학생 필터가 남는 문제를 지적하여 reset을 추가하고 별도 회귀 검증 중이다. 마지막 독립 재검토는 사용량 제한으로 종료되어 그 검토를 통과했다고 적지 않는다. 실제 로컬 DB에는 관리 이력이0건이므로 원문 검사는 명시적 네트워크 fixture, 실제 브라우저는0건/전체60명 선택 상태를 확인했다. 원본 DB에 검수용 상담을 임의로 저장하지 않았다.

## 전체 통과를 막는 의미 문제

G11/G14/G22/G26/G48/G50: 이전 BE는 일정 없는 날도 미제출로 계산하고, 입실은 기간 전체 원시 시각 평균을 비교한다. 최근 등원 요일 구성이 달라진 것만으로 정상 학생이 표시될 수 있다. 과목 계획/실제도 날짜 표본이 다르다. 이를 그래프 개선만으로 해결됐다고 기록하지 않는다. 공식 버전3의 계약과 반례부터 작성하여 수정 중이다. 기존 상담 snapshot은 버전1/2로 보존하고 새 공식과 재비교하지 않는 호환 처리가 필요하다.

G01–G54 체크박스는 항목별 증거 기록과 남은 결함 해결 후 갱신한다. 이 문서는 현재 상태이며 전체 완료/사용자 승인/효과 검증을 뜻하지 않는다.
