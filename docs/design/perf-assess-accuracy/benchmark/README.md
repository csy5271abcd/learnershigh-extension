# 평가계획 추출 정답 세트 (truth.jsonl)

판정 묶음 두 개(1123, 1124; 각 10개교)에서 원문에 있는 과목마다 한 줄씩, 원문 기준 정답 값을 적었다. 모두 1,212행이다.

## 행 형식

```
{"batch","school","filePrefix","subject","category","exam","perf","tasks":[{"name","w"}],"noTask","source","from",
 "passFail"?, "unresolved"?, "why"?, "doubt"?, "judgedRow":{"schoolIdx","id","verdict"}}
```

- `from`: `O-output` = O·O-NOTASK 행이라 판정한 결과 값을 그대로 옮김. `note` = 판정 비고에 값이 다 있어 그대로 씀(과목명만 틀린 행은 결과 값에 비고의 과목명을 씀). `original` = 원문을 열어 읽음.
- `category`: 1124는 판정표의 계열 칸, 1123은 과목명 사전 규칙으로 매김.
- `passFail`: 이수(P/F) 과목(지필·수행 0/0, 과제 없음).
- `judgedRow`: 판정표의 행 번호와 판정. MISSING 행은 `M1`, `—`, `-` 같은 표의 표기를 그대로 둠.

## 확인한 것

- 모든 행의 과제 이름이 `source`에 적힌 원문 파일 안에 있는지 글자로 대조했다. 공백은 무시했다. 비고에서 가져온 행 가운데 원문 이름과 다르게 줄여 적힌 2개(석정여고 생활과 과학, 수일고 생애 설계와 자립)를 찾아 원문 이름으로 고쳤다. O 행 6개는 원문 텍스트를 뽑을 때 특수문자나 칸 나눔이 달라져 글자로는 맞지 않았지만, 판정에서 O를 받은 행이라 그대로 두었다.
- 석정여고 X-FAKE 13개는 판정한 결과 행의 쪽 번호가 다른 과목 표를 가리켰다. 그래서 `source`를 그 과목의 실제 쪽으로 고쳤다.
- O가 아닌 행 10개를 무작위로 골라 원문을 다시 열어 비율과 과제를 확인했다. 10개 모두 맞았다(석정여 여행지리·윤리와 사상, 건국대 통합사회2, 광교 음악, 부산장안 윤리문제탐구, 청원 공통영어2·생명과학Ⅱ, 수일 세계지리·세포와 물질대사, 강일 세계문화와 영어).
- 남은 한계: 과제별 비율(`w`)은 비고에서 가져온 행이면 비고 숫자를 그대로 믿었다. 과제 이름이 원문 칸 이름의 일부만 적힌 경우는 위 대조로 다 잡히지 않을 수 있다.
