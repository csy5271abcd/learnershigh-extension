# 학생 케어 시안: 맥락 없는 읽기 검토

2026-10-24. 이전 대화·설계 의도·소스를 전달하지 않은 새 에이전트 두 개에게 실제 화면 캡처만 제공했다. 첫 검토는 1600px 세 화면, 두 번째는 1600px 시안 1/3과 850px 시안 2다. 답변은 AI의 정지 화면 해석이며 실제 관리자 실험, 정량 사용성 점수, 클릭 성공 검증이 아니다. 클릭 동작은 작성자가 브라우저와 Playwright로 별도로 확인했다.

## 읽은 내용
두 에이전트 모두 개인/학습관 화면의 목적과 선택 학생·날짜 범위를 읽었다. 개인 화면에서 미입실 10/13·17·20·24, 미제출 10/18·19·20·21을 식별했다. 10/20의 동시 미입실·미제출과 입실했지만 제출하지 않은 날을 구분했다. 학습관에서는 실제 경고 항목을 가진 학생과 기록 부족 학생을 식별했다. 확대·날짜·지표 셀을 상세 진입 후보로 읽었다.

## 지적과 변경
- 시각의 집계 방식 불명확 → ‘평균 입실 시각’으로 표시.
- 전체 14일과 요약 7일 혼동 → 전체 선택을 ‘날짜 보기’로 이름 붙이고 요약 옆 집계 기간, 그래프 옆 실제 날짜 범위를 분리.
- 이전 3주 평균의 단위 불명확 → 학습 시간은 ‘이전 3주 주간합계 평균’으로 표시.
- 계획 달성률이 항목 완료율인지 시간 비율인지 불명확 → ‘학습 시간 기준’ 범례.
- 과목 계획/실제를 전후 변화로 오독 → 시간 흐름 화살표 제거, 계획 ○/실제 ●와 과목명을 수치 옆 표시.
- 학습관의 7일 상태와 14/28일 그래프 기간 혼동 → 상태 열에 시작·종료 날짜, 공통 안내에 구분 표시.
- 경미한 차이와 관리 기준 초과를 혼동 → 기준에 해당하는 셀에 색과 ‘!’ 표식 병용. 기준 설정 진입 유지.
- 날짜 카드의 클릭 가능성 불확실 → 날짜 칸에 ↗ 표시. 학생 이름도 학생별 화면으로 연결.
- 0과 기록 없음의 모호함 → 알려진 0은 ‘학습 없음’, null은 ‘기록 없음’으로 표시하며 상세에는 정확한 시간 표시. 예정 등원일이 없으므로 미입실을 결석으로 명명하지 않는다.
- 확인 예정일 누락 → 확인일이 지난 행에 날짜 표시.

## 별도 코드 검토와 화면 검사
- 접근성 이름이 현재 수치를 덮음 → 수치·기간·비교값을 접근성 설명에 포함.
- 학생마다 다른 시간량 그래프 눈금 → 학습관에서는 같은 항목에 공통 눈금 사용.
- 학습관 마지막 행이 첫 화면 아래에 위치 → 행 밀도 조정 후 1600×1000에서 전체 10명 표시를 자동 검사.
- 원본 소스 22개 파일을 git object hash로 대조. 수정 없음.

## 남은 한계
학습관의 작은 그래프는 패턴을 훑는 용도다. 정확한 일별 시각·날짜·계획 시간은 셀을 눌러 상세에서 확인한다. 390px에서는 가로 표를 내부 스크롤하며 개인 화면은 세로로 쌓인다. 28일 보기와 많은 학생을 모든 화면 크기에서 무조건 무스크롤로 표시한다는 보장은 하지 않는다. 최종 화면의 읽기 속도·정답률·선호도는 실제 학습관 관리자에게 검증해야 한다.
