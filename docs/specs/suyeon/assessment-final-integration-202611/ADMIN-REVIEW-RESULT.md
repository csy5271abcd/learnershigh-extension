# Admin 평가계획서 검토 결과 (2026-11-10)

도달 수준: **브라우저 조작 검증 완료.** 검토 확정은 **합성 PDF·E2E 전용 DB에서 Mock 관리자(`adm_plan_operator`)로 실행한 합성 데이터 기반 API 시험**이며 실제 사람 검토가 아니다. 실제 학교 문서는 확정하지 않았다.

## 1. 과목 ID 매핑 방식 — 직접 입력 + 서버 검증 (지시서 B안)

| 확인 | 결과 |
|---|---|
| 관리자가 쓸 수 있는 공식 과목 목록 API (A안) | **없음.** 계약 §34 학생 상세 응답 Shape 미정, 학교·과목 원천 미정(API-OD-A01, OD-A04) |
| 학생 API로 과목 얻기 | 하지 않음(다른 학생 가장·권한 밖 호출 금지) |
| 확인 가능한 과목 ID 출처 | Backend 학업 Context 경계 `AcademicContextProvider`. 지금 구현은 **개발용 Mock**(`MockAcademicContextProvider`: `school_001` 1학년 1학기 `subj_11~14`, 2학기 `subj_01~04`) |

구현:

- 화면: AI 분석 과목명·원문 쪽 범위 옆에 "학업 과목 ID" 입력칸. 자동 선택·과목명 추측 없음. 상태는 "미연결 / 입력됨 · 서버 확인 전".
- Backend(신규 검증): 확정 요청의 `reviewedSubjects[i].subjectId`가 그 문서의 **학교·학년도·학년·학기 슬롯 과목**이 아니면 400 `VALIDATION_ERROR` `reviewedSubjects[i].subjectId: unknown`, 저장 없음. 계약 §39 "확인 결과의 공개 범위는 학교·학년도·학년·학기로 제한"을 서버에서 지키는 검증이다. 새 오류 코드는 없다.
- 과목 **이름**은 관리자 화면에 보여줄 원천이 없어 표시하지 않는다(ID만).

## 2. 원본 대조

- 서버는 원본 PDF 바이트를 보관하지 않는다. 서버 원본 보기·다운로드는 제공하지 않는다.
- 관리자 Revision 응답에 `checksum`(서버가 등록 때 계산해 저장한 SHA-256)을 추가했다(§48 File Contract 필드 이름).
- 관리자가 자기 PC의 원본 PDF를 고르면 **브라우저에서만** SHA-256을 계산해 비교한다(파일을 보내지 않음).
  - 일치: 브라우저 PDF 보기(로컬 파일 Object URL)를 열고, "대조했다" 확인 체크를 켤 수 있다.
  - 불일치·계산 실패·서버 checksum 없음: 확인 체크와 확정 버튼이 비활성이다.

## 3. 검토 화면 (http 모드)

1. 기존 영역 유지: 외부 분석기 후보 안내·분석기 버전·확인된 값·경고·후보 표(과목·지필·수행·채점 기준·원문 대조).
2. 신규 "검토 확정" 패널: ① 원본 PDF 대조 ② 학업 과목 연결 ③ 확인할 필드 표(AI 후보 / 확정할 값 / 근거 PDF 쪽, 분석기 근거 쪽 표시) ④ "원본 해당 쪽과 직접 대조했고 확정합니다" 체크 → 확정 버튼.
3. 확정 대상 필드: Backend `fieldPath` 규칙 안의 단일 값 — 지필·수행 반영 비율, 시험별 비율·만점·시기, 수행 항목 이름·비율·만점·시기. 제출물·조건·채점 기준(목록 값)은 보기만 하고 확정 대상에서 뺐다(값 단위 편집 규칙 없음).
4. 빈 값으로 확정 = "원문에 없음 확인"(null). 0으로 바꾸지 않는다.
5. 확정 버튼이 켜지는 조건: 분석 결과 있음(`analysisId`) · 상태 `REVIEW_REQUIRED` · 미확정 Revision · 원본 SHA-256 일치 · 필드 1개 이상 · 확인 필드의 과목 ID 입력 · 값 있는 필드의 근거 쪽(1~쪽 수) · 숫자 필드는 숫자 · 확인 체크. 안 되면 이유 목록을 보여준다.
6. 확정 → PUT review → **분석·문서를 다시 조회**해 서버 확정값·상태를 보여준다.
7. 이미 `CONFIRMED`인 Revision은 "재검토 정책 미확정"으로 추가 확정을 막는다(이전 검토 취소·덮어쓰기·삭제 없음).
8. Mock 모드 검토 화면은 기존 그대로다(패널 없음, 브라우저 확인).
