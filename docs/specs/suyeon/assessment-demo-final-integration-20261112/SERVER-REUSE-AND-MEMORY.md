# 서버 재사용과 메모리 관리

| 원칙 | 실제 |
|---|---|
| 사용자 서버 종료·재시작 | **하지 않음** (Backend·5173·5174·MySQL·분석기 그대로) |
| 임시 Vite 서버 | 이번 작업에서는 띄우지 않음(이전 작업의 5184~5196 검증 서버는 모두 정리됨, 명령줄 확인 0개) |
| Backend 변경 | **없음** → jar 재빌드·재시작 불필요 |
| Frontend 변경 | Vite HMR로 5173·5174에 반영(새로고침으로 확인) |
| 분석 | 문서 1개씩 순차(최대 4초/건), 결과는 파일로 저장 후 요약만 메모리에 |
| 브라우저 | Playwright Chrome 1개씩 순차, 파트마다 종료 |
| 여유 메모리 | 시작 약 1.0GB → 작업 중 1~2GB 범위 |

이전 세션에서 분석기 시작 명령(`service.ps1 start`)의 대기 셸이 메모리 부족으로 강제 종료됐지만 분석기 프로세스는 살아 있었다(이번에 `/health` 200 확인 후 재사용).
