## 확인 방법

- 수정 직후 같은 ID를 학생 API와 담당 지점 관리자 API로 다시 읽어 마감일·제목·상태가 같은지 확인(실패 0).
- 15개교 대표 학생 화면에서 학생별 전체 수행평가 마감일이 기준일 이후인지 확인(`STUDENT-UI-VERIFICATION.md` 마감일 항목 15/15).
- 1학기 수행평가도 요청에 따라 미래 마감일로 바꿨다. **합성 시연 일정**이며 학년도·학기 메타데이터와 원본 평가계획서 공식 평가 시기는 바꾸지 않았다.

원자료: Seed Manifest `deadlineTitleUpdates`(실행 요약 2회: 변경 1회 + 멱등 재실행 1회), 건별 `previousDeadlineDate`(제주고 19건은 Seed 재실행으로 이력 필드 유실). `deadline-title-update.json`은 멱등 재실행 결과(변경 0)로 덮어써진 상태 — 스크립트를 고쳐 이후에는 `deadline-title-rerun.json`에 따로 쓴다.
