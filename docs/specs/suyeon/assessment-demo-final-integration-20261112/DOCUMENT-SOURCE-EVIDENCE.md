# 평가계획서 분석 근거(Locator)

| 형식 | 근거 표현 | 확인 |
|---|---|---|
| PDF | 물리 쪽 번호(`pdfPageNumber`) + 표 위치 + 인용 | 5174 검토 화면에 근거 쪽 표시(합성 PDF). 실제 PDF 3건의 항목별 근거는 이번 요약에서 읽지 못해(요약 스크립트가 PDF Locator 필드를 찾지 못함) **미검증** |
| HWP | `구역 · 표 · 행 · 열 · 경로(p3.c0.r2c1) — "원문 인용"` | 5174 검토 화면 캡처(`screenshots/admin-plan-review-hwp.png`). **가짜 PDF 쪽 번호 없음**(payload에 `pdfPageNumber` 없음, 분석기 `officialPdfContract.importable=false` 사유 "HWP/HWPX에는 쪽 번호를 만들지 않는다") |
| HWPX | HWP와 같은 구조 | 미리보기 응답 확인(인용 일치 100%) |

## 인용 일치 (분석기 자체 검사 수치 — 실제 문서 인용의 사람 대조는 하지 않음)

| 문서 | Locator | 인용 원문 일치 | 위치 일관성 |
|---|---:|---:|---:|
| 가좌 수학과 HWP | 323 | 323 | 323 |
| 대신 심리학 HWPX | 5 | 5 | 5 |
| 대신 물리학Ⅱ HWPX | 5 | 5 | 5 |
| 대신 인공지능 수학 HWP | 3 | 3 | 3 |
| 대신 문학과 영상 HWP | 3 | 3 | 3 |

**주의**: 인용이 원문에 있다는 것과 그 인용이 **올바른 평가 항목에 연결됐다**는 것은 다르다. 표본에서 연결 오류를 확인했다(물리학Ⅱ 시기 칸, 충무 "2차 시험" 결합) — `DOCUMENT-EXTRACTION-ACCURACY.md` §3.

## 원본 대조 경로

- PDF: 서버가 원본을 보관하지 않으므로(`fileRef=null`) 관리자는 갖고 있는 원본을 고르면 브라우저에서만 SHA-256을 계산해 대조한다(파일 전송 없음). 검토 화면 안내 그대로.
- HWP·HWPX: 브라우저 원본 보기 **미지원**. 한글 프로그램에서 Locator 위치를 직접 대조하라는 안내가 화면에 있다. 원본을 브라우저로 볼 수 있다고 주장하지 않는다.
