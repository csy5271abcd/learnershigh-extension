- **노트 v4** (`note_8e7c0524-…`, `rev_4c0de497-…`)

  - 사실 범위: 1863 고종 즉위 ~ 1889 함경도 방곡령까지 교과 수준의 확인된 사실만 썼다. 모둠 토론 같은 활동은 "학생 활동 기록(합성)"으로 표시했다.
  - 이전 버전: v1~v3 보존. 피드백 Snapshot은 그대로 `rev_ab9fdd09-…` + 당시 PDF 버전 `version_104100cd-…`(locked).
- **PDF v5** `김민서_한국사2_탐구보고서.pdf` (A4 4쪽)
  - 내용: 표지(운정고 1학년 2반 1번 김민서·한국사2·수행평가명), 동기, 질문·목표, 역사적 배경, 연표 표 12행, 연표 그림, 정책 전환, 조약 비교표, 분석, 과정, 결론, 참고자료.

  - 이전 버전: v1~v4 보존. v4에는 "합성 예시 목록" 출처와 근거 없는 사건 수 그래프가 있어 v5로 교체했다.
- **PNG v1 (신규 결과물)** `김민서_한국사2_개항기_연표.png` (1920×1080)
  - 내용: 1863~1889 사건 12개 연표(통상 거부·개항 시기 구분)와 강화도 조약·조미 수호 통상 조약·조일 통상 장정 비교표.
  - 통계 수치는 없다. SHA-256 `8cf147eb…`.

## 6. 남은 문제

- 수행평가 제목에 시드 표식 `[DEMO-15S-2026]`이 Student·Admin 화면에 그대로 보인다.
  - 시드 검증 스크립트가 이 표식을 쓰므로 바꾸지 않았다.
- 김민서 목록에 이전 UI 검증 과제 "[UI] 모달 등록 확인 stu_demo_001"이 1건 있다. 삭제하지 않았다.

- 분석 결과가 학생 수행평가로 자동 등록되는 기능은 없다.
- 지점 관리자는 공식 평가계획서 등록·확정을 할 수 없다(OD-A08).
