## 확인 항목

- Backend 저장: 학생 API `GET notes?sourceId=` 재조회로 노트 ID·Revision 확인(Local State만 저장이면 실패로 판정).
- 새로고침 후 편집기 제목·블록 값에 작성 문구 유지.
- 관리자: 학생 기록 화면 **"관리자 기록 도구" 탭**에 최신 Revision 본문 표시(기본 탭 "학생 화면"은 읽기 전용 iframe) + 관리자 API 같은 noteId.
