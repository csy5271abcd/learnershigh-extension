## 판정 요약

- **10개교 모두 실제 파일과 분석 기록이 있다.** 제외할 학교는 없다.
- 수정이 필요한 표현:
  1. 대신고를 "감점형을 분석한 사례"로 쓰는 것 → "감점형이라 **추출하지 못한** 사례"로 고친다.
  2. 휘문고를 학교 전체가 가로형인 것처럼 쓰는 것 → 해당 파일(F01124)로 한정한다.
  3. 현일고 G013을 성공 사례로 쓰는 것 → 실패·개선 사례로 쓴다.
  4. 인용 일치(154/154 등)를 정확도로 쓰는 것 → 금지.
- 새로 추가하면 좋은 학교(기존 10개에 없는 기술 문제):
  - 광명고 — HWP→HWPX 같은 양식, 코퍼스 최대 병합
  - 김포고 — 134행 병합, 가로형 요약 124
  - 고운고 — 학교 전체 통합으로 과목 분할 실패
  - 세종고 — 상·중·하 + 배점, 기본점수 감점 규정
  - 자양고 — 중첩 39, 격자 모호 59
  - `paichai` — 스캔
  - `samgaksan` — 머리글 오인 오류
