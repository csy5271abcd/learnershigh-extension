# Student ↔ Admin 같은 데이터 확인 (2026-11-11)

## 1. 실제로 양쪽에서 같은 DB 데이터가 보이는 흐름

| 흐름 | 결과 | 근거 |
|---|---|---|
| Admin PDF 등록 → 자동 분석 → 원문 대조·확정 → Student 공식 평가정보 조회 | **동작 (기존 기능 + 이번 자동 분석 연결)** | 확정·학생 노출은 기존 PDF 브라우저 43·HTTP 33. 이번에는 등록 → 실제 분석기 → 수신 → 검토 페이지까지 13/13(격리 환경). 확정 → 학생 조회는 이번에 다시 돌리지 않음 |
| Student 수행평가 등록 → Admin 학생별 수행평가 조회(지점 범위) | **API 수준 동작 (기존)** | `e2e_v211.py`의 관리자 학생 조회·타 지점 거절. Admin **화면**에서는 학생 목록이 연결 전이라 진입 불가 |
| Student 분석 미리보기 ↔ Admin | **연결 없음 (의도)** | 미리보기는 저장하지 않는 개발 기능. 공식 정보·관리자 확정과 분리 |

## 2. 요청된 E2E 시나리오 상태

| ID | 시나리오 | 상태 |
|---|---|---|
| E2E-01 | Student 5173·Admin 5174 실행, Router, Sidebar, http, Mock 인증 Header, 직접 접속, 새로고침 | **통과** (두 화면 렌더링·콘솔 오류 0, 분석 페이지 직접 URL·새로고침 시험 포함) |
| E2E-02 | 수행평가 POST → MySQL → GET → PATCH → 새로고침 | 기존 기준선(PDF 브라우저 43)에 포함. **이번 재실행 안 함** (B-7) |
| E2E-03 | 노트 r1/r2 | **불가** — 테이블 없음 (B-1) |
| E2E-04 | 결과물 v1/v2 | **불가** — B-1·B-2 |
| E2E-05 | 피드백 요청 → Admin 대기열 → 답변 → Student 조회 | **불가** — B-1 |
| E2E-06 | 성장 기록 | **불가** — B-1 |
| E2E-07 | 중요 표시·참고자료·관리자 공개 자료 | **불가** — B-1 |
| E2E-08 | Admin PDF 등록 → 실제 분석 → 전체 페이지 → 원문 대조 → 확정 → Student 공식 정보 | 등록~전체 페이지 **통과(13/13)**. 확정→학생 조회는 기존 43에 있으나 이번 재실행 안 함 |
| E2E-09 | PDF·HWP·HWPX 실제 분석 → 전체 페이지, 공식 확정 차단 | **통과** (Student 30/30, Admin HWP·HWPX 각 15/15, 확정 비활성) |
| E2E-10 | 분석 결과 페이지 전용(Student·Admin) | **통과** (Modal 결과 제거 확인, 뒤로·새로고침·직접 URL) |
| E2E-11 | Student 노트·파일 → Admin 같은 학생 조회 | **불가** — B-1 |
| E2E-12 | 오류·권한 | 손상 파일·분석기 연결 실패·Backend 연결 실패(직전 보고서), 타 지점 차단(기존 33). DB 저장 실패·중복 요청은 이번 미시험 |
| E2E-13 | 1920×1080 화면 | 분석 결과 페이지는 1920×1080 캡처 확인. 다른 화면은 이번 미시험 |

**결론: "학생이 쓴 노트·결과물·피드백을 관리자가 보고 답한다"는 핵심 왕복은 DB 테이블 승인(B-1) 전에는 실데이터로 만들 수 없다.** 화면 자체는 Mock 모드에 있으나, Mock Store는 Student·Admin이 따로 갖고 있어(포트별 메모리) 지시서 §28의 "서로 다른 Mock Store에 따로 저장되어서는 안 됨"을 만족하지 못하므로 완료로 보고하지 않는다.
