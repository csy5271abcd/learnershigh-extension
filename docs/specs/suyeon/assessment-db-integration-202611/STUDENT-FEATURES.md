# Student 기능 실제 구현 상태 (5173, http, 같은 DB)

| 기능 | 상태 | 확인 |
|---|---|---|
| 수행평가 등록·조회·수정·상태 | 실데이터 (기존) | 이번 교차 E2E에서 생성·상세 조회, 이전 기준선 |
| 탐구 노트 생성(템플릿 10종 중 선택) | **실데이터** | 화면 "실험 보고서" 템플릿 → `POST /notes` 201 → "저장됨 · v1" |
| 노트 자동 저장·Revision | **실데이터** | 입력 → `PUT` 200 → v2, DB Revision 2개, r1 본문 불변, 새로고침 후 유지 |
| 노트 충돌 | **서버 검증** | 오래된 expectedRevisionId 409 (통합 테스트). 화면의 충돌 안내는 기존 UI 그대로 |
| 노트 블록(목록·체크리스트·표·링크 카드 등) | 저장됨(임시 형식) | `attrs` 객체로 보존. Editor 저장 형식 확정 전(OD-A05)이라 안내 문구를 "임시 형식"으로 수정 |
| 결과물 등록·새 버전 | **실데이터 + 실제 파일** | 화면 업로드 v1·v2, 버전 독립 증가 |
| 결과물 내려받기 | **실데이터** | 화면 버튼 → 서버 권한 검사 → 원본 바이트(SHA 일치). 앱 안 미리보기는 미제공 안내 |
| 피드백 요청 | **실데이터** | 화면 버튼 → Snapshot(노트 r2 + 결과물 v2) PENDING, 요청 후 노트 수정해도 Snapshot 불변 |
| 피드백 확인 | **실데이터** | 관리자 전달 후 목록 "답변 완료", 상세 패널에 의견 표시. 초안은 안 보임 |
| 성장 기록 작성·수정·조회 | **실데이터** | 화면 작성 → 저장 → 직접 URL 재조회 유지, 목록 표시. 학교생활기록부가 아니라는 기존 안내 유지 |
| 중요 표시 | **실데이터** | 목록 별표 → `PUT /archive/favorites` → 보관함 중요 탭(새로고침 유지) |
| 보관함(최근·완료·지난 학기) | 실데이터 | 학교 수행평가 기준. 휴지통은 항상 빈 목록(삭제 정책 미결) |
| 개인 자료함 등록·수정 | 실데이터 (API 시험) | 화면 등록 Modal은 기존 그대로 http 연결. 다른 학생에게 안 보임 확인 |
| 선생님이 공개한 자료 | **신규, 실데이터** | 자료함 하단 영역, 관리자 공개 후 표시 |
| 추천 자료원(과목별) | **연결 전** | 과목 이름 매핑이 Mock 학업 정보에 묶여 있어 http에서는 기존 "연결 전" 유지 |
| 평가계획서 분석 결과 전체 페이지 | 유지 | 이전 작업(30/30) |
| 심화 탐구 정적 참고자료 | 유지 | 이전 작업(36/36) |

노트·결과물·피드백의 대상은 **학교 수행평가만**이다(심화 Task는 2026-11-03 폐기, http에서는 빈 목록).
