## 3. 시험 중 고친 것 (숨기지 않음)

| 증상 | 원인 | 조치 |
|---|---|---|
| 관리자 학생 기록 행이 열리지 않음 | http 모드에서 예전 "제한 목록" 컴포넌트를 쓰고 있었음 | 전체 학생 상세 화면 사용, 기본 학기 = 개발 현재 학기 |
| 별표가 저장되지 않음 | 화면이 중요 목록을 200건 요청, Backend 최대 100 → 400 | 보관함 조회 최대 500 |
| 관리자 참고자료실 첫 탭 오류 | 정적 자료원 카탈로그가 http에서 "연결 전" | Student와 같은 정적 원천 사용 |
| 성장 기록 작성 화면 관련 활동 오류 | 폐기된 심화 Task 목록이 http에서 503 | http에서는 빈 목록 |
