# Admin 기능 실제 구현 상태 (5174, http, 같은 DB)

| 기능 | 상태 | 확인 |
|---|---|---|
| 학생 목록 | **실데이터** | 담당 지점(강남) 학생 10명, 이름·학교·학년(개발용 Mock 원천), 활동 수는 DB에서 계산 |
| 학생 상세(학업 정보·수강 과목) | **실데이터** | 기존 "서버 계약 없음" 제한 화면을 없애고 전체 화면 사용 |
| 학생별 수행평가·성장 기록·피드백 이력 | **실데이터** | 같은 학생·같은 ID |
| 학생 기록(관리자 기록 도구): 노트 Revision·결과물 버전 | **실데이터, 읽기 전용** | 교차 E2E에서 최신 노트(v3)·결과물 v1·v2 표시 |
| 결과물 내려받기(관리자) | 실데이터 (API 시험) | 담당 범위만, 다른 지점 404 |
| 학생 화면 보기(읽기 전용) | **연결 전** | 학생 전체 Snapshot API가 없어 "연결 전" 안내. 기록 도구 탭으로 같은 데이터를 볼 수 있음 |
| 피드백 대기열 | **실데이터** | 학생 요청이 바로 보임(제목·학생·상태) |
| 피드백 상세(요청 당시 노트·파일) | **실데이터** | 요청 후 학생 수정분이 섞이지 않음 확인 |
| 피드백 초안 저장 | **실데이터** | 학생에게 안 보임 확인 |
| 피드백 전달 | **실데이터** | DELIVERED, 학생 확인, 재전달 409, 수행평가 상태 불변 |
| 참고자료실 등록·수정 | 실데이터 | 기본 비공개 |
| 참고자료 학생 공개/비공개 | **신규, 실데이터** | "학생에게 공개" 버튼 → 학생 자료함 표시 |
| 참고자료 삭제 | **연결 전** | 보존 정책 미결로 Backend DELETE 없음 |
| 추천 사이트(자료원 카탈로그) | 정적 | Student와 같은 정적 원천을 읽음(Mock 아님) |
| 전체 현황 KPI | 기존 그대로(Mock 계산) | http 연결은 이번 범위 밖 |
| 평가계획서 등록·자동 분석·검토 전체 페이지·PDF 확정 | 유지 | 이전 작업(PDF 13/13) |
| HWP·HWPX 공식 확정 | 차단 유지 | `HWP-HWPX-REVIEW.md` |

관리자 ID: 시연용 개발 Mock 관리자 `adm_demo_gangnam`(강남 지점 학생 + school_001 평가계획서). 화면 상단에 "개발용 Mock 인증"이 표시된다. 운영 권한이 아니다.
