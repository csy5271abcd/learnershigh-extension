# 실제 측정된 실험·검증 결과

> 원칙: 실제로 측정·실행된 수치만 적는다. **테스트 통과 수는 정보 추출 정확도가 아니다.** 사람 정답이 0건이라 Precision·Recall·Field Accuracy는 한 번도 계산되지 않았다.
> 이번 조사는 테스트를 다시 돌리지 않았다(시연 환경 보호). 아래는 기존 실행 기록과 저장된 결과를 읽어 정리한 것이다. 다만 원본 코퍼스 해시 대조는 이번에 새로 실행했다.
