## 5. `MONTH_RANGE`·`WEEK_UNRESOLVED` 표시 — **완료(실제 B13 HTTP)**

- **수신·저장**

  - F01912: `MONTH_RANGE` 40행(원문 39), `WEEK_UNRESOLVED` 1행(원문 보존, 만들어진 날짜 0).
- **관리자 Wizard**
  - 달을 넘는 범위: "4~5월 여러 달 · 원문 “4월3주-5월1주”"
  - 끝 달 생략: "4월 · 주차 (기준 미확인) · 원문 “4월 4주 ~ 3주”"

- **학생 Planner**: 월 범위·원문 표기가 보인다. 시험 슬롯이 2학기라 실제 1학기 문서의 3~7월 행은 '이 학기 달 밖의 계획'으로 모였다(기존 규칙대로, 날짜 생성 없음).

## 17. B 측 확장 응답 활성화에 필요한 조건
