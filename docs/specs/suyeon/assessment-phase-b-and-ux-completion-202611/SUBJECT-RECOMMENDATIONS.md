# 과목별 추천 자료원

## 원천

검토된 정적 카탈로그다(AI 추천 아님). 기존 참고자료 24곳을 쓴다: `references/reference-link/learnershigh-assessment-subject-reference-links.md` 기준, `api/mock/referenceSourcesFixture.ts` 원문 그대로. 링크는 실제 대표 홈페이지 주소다. 원문에 검색어가 없어서 추천 검색어는 만들지 않았다.

서버 API(§22 recommendations)는 만들지 않았다. 정적 자료를 DB에 복사하지도 않는다.

## 과목 연결 (정규화)

과목 **이름**을 영역으로 바꾼다(`model/referenceAreas.ts`, 기존 규칙). `subj_11` 같은 ID는 하드코딩하지 않아서 학교마다 과목 ID가 달라도 같은 규칙으로 동작한다.

| 영역 | 이름 규칙 예 |
|---|---|
| 화학·생명과학 | 화학 / 생명·생물 |
| 정보 | ^정보·인공지능·프로그래밍 |
| 한국사·역사 | 역사·한국사·세계사 |
| 수학 | 수학·미적분·확률과 통계·기하 |
| 국어 | 국어·문학·화법·작문·독서 |
| 과학 | 물리·통합과학·과학탐구 |
| 사회 | 사회·정치·경제·윤리·지리 |
| 영역 없음(영어·예체능 등) | 일반 자료원(도서관·논문·학술·통계)으로 대체하고 화면에 그렇다고 표시 |

일반 자료원도 없으면 "추천 자료 없음"을 보여 준다. 오류(503)로 끝나지 않는다.

## Student 자료함

과목 선택 → 영역 표시 → 유형 칩 필터·자료원 검색 → 자료원 선택 → 설명·실제 링크(새 창, `noopener noreferrer`) → "이 자료원에서 찾은 자료 추가". 추가하면 출처 이름이 채워진 자료 추가 Modal이 열리고 §22 `POST /resources`로 MySQL에 저장한다. 열람 여부는 표시하지 않는다.

## Admin 참고자료실

같은 정적 원천(추천 사이트 탭, 과목 영역 칩)을 쓴다. "자료 저장"으로 관리자 스크랩(DB)에 저장하고 "학생에게 공개"를 누르면, 학생 자료함 "선생님이 공개한 자료"에 나온다. 추천 카탈로그(정적)와 관리자 공개 자료(DB)는 서로 다른 원천이다.

## 검증 (E2E)

- 통합과학1 → 과학 영역 자료원 표시, 실제 https 링크 확인
- 화면에서 저장 → MySQL 재조회
- 관리자가 추천 사이트에서 저장 → 공개 → 학생 자료함에 표시
