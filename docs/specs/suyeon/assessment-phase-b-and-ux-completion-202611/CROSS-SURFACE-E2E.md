### 실행 중 고친 것 (숨기지 않음)

| 증상 | 원인 | 조치 |
|---|---|---|
| 비교 화면 PDF "로드하지 못했습니다" | E2E 합성 PDF가 머리글만 있는 가짜 파일 | E2E가 유효한 PDF(xref 포함)를 만들도록 고침. 실제 렌더링을 캡처로 확인 |
| 학생 화면 보기 상단 "선생님께 피드백 요청" 활성 | 읽기 전용에서도 버튼이 보였음(누르면 탭 이동만, 쓰기는 Guard가 막음) | 읽기 전용이면 숨김. E2E 검사를 "활성 쓰기 버튼 0"으로 넓힘 |
| 검토 점검표·확인 문구가 오른쪽 끝으로 밀림 | `listRow` 양끝 정렬 | 왼쪽 정렬 |
