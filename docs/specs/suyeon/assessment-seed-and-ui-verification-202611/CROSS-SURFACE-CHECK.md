# Student ↔ Admin 비교

## 실제 DB 데이터 (같은 ID)

| 항목 | Student (작성·관리) | Admin (조회·피드백) | 같은 값 확인 |
|---|---|---|---|
| 수행평가 4 | 목록·상세·상태 | 학생 상세 4건, 학생 화면 보기 경로 4건 같은 `assessmentId` | PASS |
| 노트 | v1·v2, 최신 v2 | 기록 열람·학생 화면 보기(읽기 전용)에 v2 본문 | PASS |
| 결과물 | PDF v1·v2, PNG 등록·미리보기·비교 | 읽기 전용, 관리자 미리보기 바이트 = v2 SHA | PASS |
| 피드백 | 요청(v2 Snapshot)·최종 답변 확인, 초안 안 보임 | 초안 저장·전달, 상세 Snapshot = v2 | PASS |
| 성장 기록 | 작성·조회 | `recordId` 동일 | PASS |
| 개인 자료 2 | 자료함 | (계약상 관리자에게 학생 개인 자료함 목록 API 없음 — 노출하지 않음) | 해당 없음 |
| 관리자 자료 | 공개 A만 "선생님이 공개한 자료" | 내 스크랩 A(공개)·B(비공개) | PASS |
| 권한 | — | 다른 지점 404, 학생 Header 위장 없음(관리자 전용 경로), 쓰기 405 | PASS |

## 정적 심화 탐구 콘텐츠

| 항목 | Student | Admin | 확인 |
|---|---|---|---|
| 탐구 라이브러리 | 8 | 8 | ID·제목·교과·목표 배열 동일 |
| 모의고사 영어/국어 | 30/30 | 30/30 | 60개 ID·과목·주제·시험·원문 유무 동일 |
| 대학별 자료 | 27 | 27 | ID·제목·대학·SHA-256·쪽수 동일 |
| 참고자료원 | 24 | 24 | ID·이름·URL·유형 동일 |
| 검색·필터 | 지원 | 지원 | PASS |
| 원문 보기 | 지원 | 지원(모의고사 원문·대학 PDF) | PASS |
| Task 생성·진행 | 없음 | 없음 | PASS |
| Backend 필요 | 없음 | 없음 (`/api` 심화 요청 0, Backend 꺼져도 열림) | PASS |

비교 방법: 두 개발 서버(5173·5174)에서 각각 콘텐츠 모듈을 브라우저로 import해 직렬화한 배열을 문자열 비교(`admin-enrichment-static-e2e.mjs` same-source 6항목). Admin은 `canonicalSource.ts`를 거쳐 Student와 **같은 파일**을 읽는다.
